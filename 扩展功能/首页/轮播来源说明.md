# 原实现迁入记录

这不是重新设计：首页DOM与CSS来自旧项目 `canvas.js/showEmptyProducts`、`canvas.css` 第49–97行；轮播模板为旧归档 `9803-a4e9a8b4bffa1b4d.js` 模块45199中的M/T/E/V及PreviewImageFrame、标签，轮播使用原先的Embla协议（循环、5000ms自动播放、交互后重设、150ms缩放重算）。固定104/40/94/382列、688×368外框、358×336结果图框、原文案和按钮均保留。

旧轮播为编译后的React组件，不能直接当Vite模块加载。本次仅将其JSX与样式依赖迁入独立目录；Next Image替换为同尺寸img，原事件转为接入层回调，资源地址改为本地中文路径。不引入归档站的登录、统计、后台请求或DOM观察器。

`轮播依赖.js` 是 Embla Carousel / React / Autoplay 8.6.0 的官方代码合并产物，只有React保持外部依赖，以共享作者工作台的同一个React实例。不重新编写轮播算法，不往作者package.json加依赖。根目录pnpm-lock.yaml锁定依赖。

构建：使用运行副本Vite所带esbuild，以 `export {default as useEmblaCarousel} from "embla-carousel-react"; export {default as Autoplay} from "embla-carousel-autoplay";` 为入口，bundle=true、format=esm、external=[react]。生成产物随精确指纹接入运行副本，不在副本直接开发。
