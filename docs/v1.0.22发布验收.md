## 修正原因

1.0.21 用跨站 iframe 导出旧 IP Origin，实际 Chrome 的存储分区返回空副本。此前隔离浏览器演练没有验证此条件，不能作为真实迁移证明。首次空备份及 browser-verified 旧记录保留供追溯；1.0.22 不信任该旧标记。

导出改用由点击同步打开的旧地址顶层窗口，严格校验窗口、Origin、会话，导出页不加载工作台。源和目标逻辑备份均落盘、读回核验后才复制；旧地址不删除。旧空副本的自动默认配置只有存在本机历史空备份及哈希证据、确切默认字段、无数据库才能恢复，其他已有业务数据继续停止。
