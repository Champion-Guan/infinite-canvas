# 上游 v0.20.0 源码升级

上游：basketikun/infinite-canvas，MIT，提交 `3a6b64b602ad062b29fac66902ed18a7ef5fd9dc`，标签 v0.20.0。比较基准 v0.19.0。当前项目版本为 v1.0.15，两个版本编号独立。

仓库此前已用 history-only 合并保留完整上游祖先，不能据此认为源码已经升级。本轮按三方差异将 19 个 Web 源码文件映射到 `src/canvas/` 并逐项解决冲突，不重写双方历史。

## 合入内容

- 画布加载后测量容器，聚焦时考虑节点面板、悬浮工具栏和底部工具栏；增加居中聚焦按钮。
- 参考图选择面板位置、节点面板随缩放保持可用尺寸、参考图选择时隐藏干扰工具栏。
- 复制节点时保留输入参考连线；粘贴时补充校验来源节点仍存在，避免悬空连线。
- 节点创建菜单翻译与紧凑布局；元素列表支持列表/网格和媒体悬浮预览，视图模式持久保存。
- 设置新增重新生成方式（默认新节点，另可覆盖原节点）、选中自动聚焦（默认关闭）、图像和视频默认分辨率。
- 删除渠道/模型后保留旧选择并阻止错误请求，不擅自改用另一个渠道查询旧任务。用户明确选择的 Fallback 保留。
- 图像质量和尺寸解耦；Gemini 分辨率从尺寸推导，插件模板增加独立 resolution 参数，视频表单补充兼容字段。
- 浏览器缺少 Storage Estimate API 时保留本地存储信息展示，不把不可获取的配额伪装成零。

## 保留的定制

质量顺序仍为自动、max、xhigh、高、中、低；max/xhigh 仍仅用于 sunburst/flare。审核、8:5/5:8、16 倍数开关、900×1200 / 800×500 等比例放大请求再缩回交付尺寸保留。产品缓存、任务隔离、提示词变量、Excel、历史排序/下载/重试/回收站、当前画布内容 ZIP 导入和 Keychain 后端代理保留。原作者 MIT 声明和页面标识保留。

不引入上游 pnpm 工作区/锁文件，因为本项目采用已有 npm 构建；不覆盖本项目 README、版本号、发布体系，不引入上游广告图片和上游进度文档。没有开发桌面客户端，桌面 .app 仍只是 Web 入口。

## Mac B 桌面入口

原实现发现桌面已有本项目入口便直接返回，导致解压位置或版本变化后仍引用旧脚本路径。修复为仅更新本项目标记的入口，不覆盖同名私人文件。健康服务已运行时无需依赖旧解压路径，直接打开对应网页；否则使用后台启动流程，失败显示固定中文提示。

Mac B 第一次使用新包需运行包内“启动工作台”入口一次，以刷新旧桌面入口。不能让已经失效、仍指向旧脚本的快捷方式自动获得尚未运行的新源码。

已生成文件、私人目录和浏览器 Origin 不变。Mac B 实机验证仍由所有者完成，本机隔离验证不能代替实机结果。
