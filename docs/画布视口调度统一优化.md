# 画布视口调度统一优化

## 原因与改动

此前平移调度的距离阈值为 `140 * k`。缩放到 5% 时，仅移动 7 屏幕像素便提交 React 状态；可视区预加载也使用固定世界距离，低缩放时覆盖过小。本次阈值固定为 140 屏幕像素，可视区预加载为 280 屏幕像素，仍保留 80ms 定期检查与快速移动的提前更新，避免边缘卡片遗漏。

小地图与定位动画原来直接调用 `setViewport`，绕过平移节流。现通过 InfiniteCanvas 的受限视口控制器复用同一调度器：逐帧绘制，周期提交，结束立即提交最后坐标。手动拖动、滚轮、缩放控件、重置及失焦可中断定位动画。小地图使用指针捕获，离开其边界仍继续拖动，释放、取消、失去捕获或卸载后结束。

Agent 快照不再依赖每次视口提交。通过实时 ref 获取当前坐标，移动期间暂停全局发布，结束同步最终视口；业务内容仍正常更新，卸载才清除上下文。沿用 React 性能检查建议，将高频相机值与全局业务广播分开。

## 验证

实际调度器模拟 60 帧、每帧 7 屏幕像素，在 5%、10% 和 100% 缩放下均为 12 次 React 提交，结束坐标精确。实际定位回调与控制器测试覆盖最终坐标、取消待执行帧、拒绝结束后晚到动画、重复结束和卸载。Agent 实际 Hook 测试覆盖实时读取、移动结束广播、业务更新和卸载清理。10 项专项通过。

这是源码与调度器回归，未量化客户机器上的 FPS。大幅快速移动仍可能每帧提前提交；周期检查仍会重新计算可见卡片和连线。若后续仍卡顿，应对重型卡片内容、可见区查询、连线数量与浏览器绘制分别采样，不能称为整个页面完全不更新。

Mac A 前端构建发布后刷新使用，不安装 Stable、不重启后端、不迁移浏览器数据。布局、主题与样式保护范围无改动，旧部署由发布脚本备份。Stable 另发 v1.0.23，后端版本标识需下一次获准重启才更新。
