# 选中卡片时的画布平移优化

版本：v1.0.20。

画布原先每帧将 viewport 写回 React，触发页面更新、可见节点筛选和选择工具栏计算。选中节点还会为相关 SVG 连线启用阴影；连线很多时，平移需要额外绘制大量滤镜。

现在鼠标移动合并到 animation frame，直接更新画布世界层、网格和选择工具栏的位置。完整 viewport 状态每 80ms 更新，或移动达到 140 个世界像素时提前更新可见范围；现有可见范围预留为 280 个世界像素。松开、取消或失焦立即提交最后位置，卸载取消未完成帧。平移期间暂停相关连线阴影，保留颜色与宽度，结束后恢复。没有改动节点位置、连线关系、数据格式或访问 Origin。

## 验证

- 完整回归 617 项通过，无失败；之后补充的 60 帧调度测量与其他调度用例共 5 项通过。60 帧小幅连续平移只需 12 次完整状态提交，仍逐帧绘制位置；这是调度测试，不是实体客户电脑 FPS 测量。
- Typecheck、构建、Lint 通过；Lint 保留 4 条既有警告。当前源码及历史敏感信息扫描通过。
- 使用隔离端口 9088、独立浏览器存储验证 120 张测试卡片、119 条连线。单选源节点时，平移前 119 条连线有阴影，平移中为 0，结束后恢复 119。
- 多选时卡片与选择框同步移动 80px/50px；快速平移后选择框仍在，打组按钮通过点击可达性检查；平移后滚轮缩放有效。
- 平移后刷新，变换位置与刷新前一致。现有页面的统计/旧兼容接口控制台报错仍存在，本次不宣称整个项目控制台无错误。

本机前端通过 publish:canvas 应用到源码模式，刷新即可看到；本次不重启 8888 后端、不安装 Stable、不迁移用户数据。客户真实大画布流畅度与 Mac B 的实机表现仍需实际使用验证。
