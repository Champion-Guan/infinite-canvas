# 多连线卡片拖动优化

## 改动

原实现以端点位置作为连线 React key，每次移动都销毁并重建关联连线。现在使用固定连线 ID，实时更新 SVG 路径。拖动期间保留高亮颜色、线宽，暂时停止 SVG 发光滤镜，释放鼠标后恢复。

坐标变化曾重新生成全部卡片的资源引用和配置输入，产生新的数组和回调，导致无关卡片重复渲染。内置节点现在使用忽略 position 的业务快照，内容、状态、尺寸、名称、顺序、成员和分组变化均失效重算。第三方插件不使用此坐标豁免，避免破坏依赖位置的 resource 回调；任务和插件 host 仍读取最新真实节点。

移动事件只安排一个待执行 animation frame，并读取最新鼠标位置；每帧只构建一次位置数组，不执行新增节点避让扫描，不重复读取容器布局。ResizeObserver 继续负责尺寸变化。松开、失焦、pointercancel 使用最终已知坐标提交，保留分组、历史、保存事务。

## 验证与边界

- 类型检查通过；Lint 无错误、4 个既有警告；构建通过。
- 30 项最终专项回归通过，包含内容快照失效、插件位置兼容、画布工作流、生成、保存排空及卡片避让。
- 独立 9088 服务和浏览器，无真实 AI 请求：181 张卡片，一张卡片连接 180 条线。旧版 120 次移动观察到 21600 个连线元素重新插入，优化后为 0；同一 SVG 元素的路径随拖动改变。
- 在 0.5 缩放下拖动并松开，刷新后位置一致；拖动期间滤镜停止、结束后恢复。没有改用户画布、凭据或代理。
- 自动化鼠标输入的 RAF 间隔中位数前后约 127/128 ms，包含浏览器控制工具调度，未证明帧率提升，不能据此宣称性能提升百分比。此轮证明减少重建和业务重算；Mac B 手感需实机验证。
- 原有浏览器插件清单 404 警告仍存在，不属于本轮拖动修复。
