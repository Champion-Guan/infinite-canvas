# v1.0.18 顶部版本与更新入口

画布顶部依次展示当前前端版本、快捷键、竖线和 Agent。版本号使用构建版本，不将 Mac A 尚未重启的旧后端版本误显示为当前前端版本。点击复用版本更新弹窗，展示本地与远端日志、检查、下载、进度和安装状态。

下载和安装通过既有受限更新接口执行。未下载、未验签、更新器不可用、首次接管或恢复未完成时不能准备安装。安装按钮先弹出保存、结束生成、关闭工作台页面的说明；取消不写设置、不请求安装。明确确认后开启确认安装设置，并发送固定确认值；仍由独立更新器执行页面检查、签名复核、事务切换和回滚。后续版本仍需新确认，不支持开窗安装。
