# 画布缩放与连线绘制优化

版本 v1.0.21。

滚轮事件原先逐事件更新 React viewport，导致可见节点筛选、节点缩放上下文及连线层重复工作。现在高频输入合并到 animation frame，世界层、网格与选择工具栏先绘制；80ms 或可见范围移动达到 140 世界像素时提交完整状态，提前更新 280 世界像素的裁剪预留。缩放结束 120ms 后及失焦时提交最终视口，快速缩放不会被较旧的 React 检查点覆盖。平移沿用同一调度器，交互期间暂停昂贵连线阴影，结束恢复。

产品参数卡片位置变化此前会使内容快照失效，从而重算提示词变量与胶囊任务汇总。内置产品参数组件不读取位置作为业务资源，现在位置变化保留业务快照，变量修改仍正常失效；任意第三方插件保持原位置敏感语义。

连线 SVG 从 10000 × 10000 且 overflow-visible 改为可见范围加预留区域，明确尺寸和 viewBox、限制绘制边界；每个连线键同时包含 ID 与端点，避免不同端点的重复 ID 复用。调整针对超大绘制层及重绘开销，不删除任何连线。另修复空白页初始化先把轮播放进新容器、再用该容器替换轮播产生的 DOM 循环异常，顺序改为先替换再放入。

调度专项验证小幅缩放不逐事件提交、大幅缩放及时重裁剪、60 帧平移仅 12 次完整提交、结束与卸载顺序；内容专项验证参数位置保留快照、变量修改重新计算。隔离浏览器使用 120 张卡片、119 条连线的产品参数源卡片连续拖动 12 次，随后 20 次缩放往返；238 条路径（每边命中区域加可见线）未增长，119 种曲线全部从当前卡片右侧中心开始，截图检查无旧起点残留。旧版本客户场景未获得确定复现，不能据此宣称所有残影根因已穷尽。

上述是调度及浏览器行为证明，不是客户实体 Mac 的 FPS 测量。节点内容、连线关系、选择操作、布局样式与持久化格式保持原功能；剩余插件索引 404 和归档页面统计请求被 CSP 拦截不在本次性能验收中。本机前端构建发布后刷新生效，后端新功能须保存关闭后重启；Mac A 不安装 Stable。
