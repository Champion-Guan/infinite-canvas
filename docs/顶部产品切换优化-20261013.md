# 顶部产品切换优化

本轮只优化产品切换，不改连线外观、拖动行为或更新安装逻辑。

## 原因与处理

点击 Excel 产品胶囊曾调用完整工作簿变更接口，重复解压、规范化、校验、压缩、写入与克隆整个工作簿。现在使用原有的按工作表保存的选择键，并缓存不可用于业务修改的轻量导航快照。缓存以存储原文为依据，真实修改、其他窗口修改及损坏内容仍会重新校验。旧 `getState()` 接口返回当前选中的 Excel 产品，避免旧业务读取错误产品。

缓存 iframe 曾用 `display:none` 隐藏，画布尺寸变为零，显示时触发重新布局。现在保持画布尺寸，使用可见性、交互禁用及可访问性属性切换；原文档不卸载。减少由胶囊与画布自身 DOM 变化触发的重复观察回调。隐藏页仅暂停媒体和 CSS 动画，不暂停生成、轮询或保存，也不暂停 React 业务 effect。

## 验证

- 39 项首轮相关测试通过；后续画布工作流、生成、保存排空、回收站及产品选择专项 37 项通过。两组有重叠，不累计为 76 个独立测试。
- 类型检查通过；Lint 无错误，保留 4 个既有警告；前端构建通过。
- 独立 9088 服务、独立浏览器数据目录：3 个 Excel 产品，每个画布 102 张文本卡片、101 条连线，工作簿含长提示词。
- 预热后连续切换 30 次，点击派发到第二个 animation frame 的中位数 45.5 ms、95 分位 164.2 ms；同步点击处理最大 30.8 ms。该指标不是实际像素绘制耗时，没有旧版本基线，不能据此宣称提升百分比或 Mac B 帧率。
- 3 个缓存画布均保持 1200×808，文档对象相同，压缩工作簿原文未因切换变更。编辑卡片后立即切换、返回及刷新，文本保留。
- 浏览器仍出现原归档页面的外网 CSP 拒绝和静态资源警告；未将其称为控制台零错误，也未在本轮扩大范围修改。
- 本机 8888 实际返回的切换脚本和数据合同脚本 SHA-256 与当前源码一致；无需服务重启。没有修改用户存储或代理配置。

首次打开未缓存产品仍需加载资源及恢复画布。缓存较多产品仍占用内存，本轮没有引入自动淘汰，避免影响后台任务。Mac B 的实际数据规模和硬件表现尚未验证。
