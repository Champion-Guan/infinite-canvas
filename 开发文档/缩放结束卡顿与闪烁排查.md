# 缩放结束卡顿与闪烁排查

目标：主图12的169节点画布，40%快速缩到5%并反向放大；过程和结束后保持即时反馈、图片连续显示，沿用五分钟安全休眠。

状态：2026-11-16已恢复连接并完成本轮实页验收。倍率反馈、图片驻留、保存和刷新恢复通过；流畅度未通过，不能标记卡顿或绘制闪烁已经解决。

## 定位与修复

1. 结果图原图恢复路径会在视区扩展后分批替换业务节点数组，进而使业务输入、正文和连线缓存失效。显示用图片现在由独立组件读取，普通预览不再为图片恢复替换整份节点数据。
2. 已显示的图片过去会在192、768及原图之间随缩放来回切换。现在保留已显示清晰度，升级前等待解码；读取失败、取消和迟到结果不清空或覆盖当前画面。图片变化通过存储键及预览修订区分。
3. 可见连线集合变化会使共享段、交点轮廓和命中路径重新计算。现在完整网络保留几何身份，屏幕SVG负责裁剪，可见关系集合仅控制键盘可访问性；缩放期间暂停连线悬停。
4. 驻留卡片不再使用会随可见范围跳变的content-visibility自动隐藏。卡片驻留、五分钟空闲机制和原数据保护不变。
5. 客户旧产品包可能有存储键但没有独立image_files原件，只有画布分片的内嵌媒体。实页中途发现只读存储键会出现空图片后，补上内嵌来源的后台缩略图恢复。预览不回写业务节点；详情、下载和生成引用明确需要原图时恢复原始媒体地址。

不修改产品数据、图片交付尺寸、原图字节或系统CPU配额；不发布版本。
