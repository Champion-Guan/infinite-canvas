# 画布、原生面板与启动主题

## 问题与调整

画布加载、弹窗打开和启动主题发生了不同来源的闪动，分别处理：

- 画布最外层原先先显示一次骨架，数据恢复时又显示一套。移除重复的 mounted 门控。`画布进入过渡.tsx` 只在等待超过 160ms 时显示加载内容；画布 ready 的同一渲染立即移除骨架，只让实际内容做 200ms 原生透明度入场。已就绪画布切回不重新插入骨架。失败仍直接显示错误与重试。
- `苹果弹窗.tsx` 不再禁用 Ant Design 的窗口和遮罩过渡，也不再额外叠加 Motion 包装动画。保留退出中的正文、标题和页脚，直到原生 afterClose 完成再释放 Presence。代次检查防止迟到关闭回调清空新窗口。总览、图片详情、回收站、设置、模型窗口及图片编辑等已有封装调用统一生效，快捷键窗口继续使用原生 Modal。
- Excel 导入改为相同 Modal；四类生成设置改为原生 Popover；工作表菜单和扩展菜单改为原生 Dropdown；画布外观改为原生 Popover。保持小型浮层的非模态交互，不新增全屏遮罩。
- Excel 下拉宽度失效来自主题 scope 的 `display: contents`，原生浮层挂到独立 Portal 后原 width 不再产生尺寸。现在使用实际 block 容器，与触发按钮同宽并保留最大宽高限制。
- 启动 HTML 原先先跟随系统切深色，全局 CSS 到达后加载页先变黑，React 挂载才恢复 SQLite 中的浅色。现在 HTML 不提前选择系统深色；SQLite 预读完成后，main 在导入界面 JS/CSS 前用纯规则应用保存主题。启动与正式主题 store 共用 `主题模式规则.ts`，不新增浏览器主题存储、数据请求或写入。

## 源码接入
