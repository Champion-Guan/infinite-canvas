# 胶囊状态透明修复

## 变更

- 原选中胶囊及其运行、成功、失败状态均显式设置透明背景，同时保持选中前景色，完全依赖单独的滑动背景层。背景层未覆盖到位时就缺少可读性保障。
- 现在静止状态由胶囊按钮自身绘制实体底色：浅色空闲为深底白字，深色空闲为浅底深字；运行、成功、失败沿用黄、绿、红状态色及对应文字颜色。
- 只在实际播放滑动时显示共享背景并临时让按钮底色透明，结束后交还实体按钮。不等待新渲染，不增加逐帧 React 状态或样式写入，保留原生弹簧距离、速度和连续改向规则。
- 播放器新增开始与结束通知；外部取消或播放失败会归位并恢复实体选中态。旧播放迟到的完成或取消回调仍受版本号保护，不覆盖新目标。
- 边缘定位提示及任务状态语义保持原逻辑，并将实体选中态约束补入基础交互动效规范。

## 验证

- 完整 TypeScript 检查通过。来源检查 659 文件一致、2132 引用，468 个顺序接入补丁。
- 已在当前 localhost:3000 页面刷新并检查。浅色选中“未命名产品8”实测按钮背景为 rgb(17,18,20)，文字为 rgb(255,255,255)，滑动标记为 false，独立指示层透明度为 0；不再依赖该层才能看见胶囊。
- 实际连续切换产品7与产品8后，选中背景归位；横向滚动至当前产品离开视野，再点击右侧定位提示，回到原胶囊后仍有实体底色。
