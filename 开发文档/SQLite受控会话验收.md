## 实现边界

| 文件 | 作用 |
| --- | --- |
| `扩展功能/本机服务/受控会话.mjs` | 可信启动器在进程内开通固定Origin的会话端口；初始化、续期、撤销；页面上限、绝对授权期限及旧令牌短暂重叠 |
| `扩展功能/本机存储/续期数据客户端.mjs` | 包装原数据客户端，不改其历史指纹；并发初始化/续期合并，校验工作区/Origin/协议/令牌，维持ACK及错误状态 |
| `开发工具/受控会话.test.mjs` | 11项针对真实本机API、SQLite与受控时钟的测试 |
| `开发工具/SQLite完整界面夹具.mjs` | 默认旧验收模式不变；显式开启`testSessionRenewal`才装配续期测试桥 |
| `开发工具/执行SQLite会话验收.mjs` | 原React界面→受控测试端口→本机API→SQLite→恢复的分边界验收 |

会话只在内存，不写业务数据库、浏览器库或URL。默认授权绝对期限8小时、最多16份页面租约、临近到期30秒内按活动请求续期，轮换令牌和CSRF；旧令牌最多重叠20秒供在途请求完成。到绝对期限、主动关闭或管理器关闭时撤销相关令牌。授权已到期不能静默重新开通，休眠过期需要可信入口重新授权。

客户端续期失败不自动重发业务请求，不生成新operationId。请求内容在等待授权前快照，调用后修改原对象不会漂移。数据库提交但响应丢失时，保留失败状态，只有使用原操作ID和相同内容显式重试才确认幂等结果。读取成功和续期成功不能抹去失败的保存。未确认操作阻止正常关闭数据客户端。

这仍是同源能力控制，不是恶意同源脚本沙箱或凭据保险箱；API Key、旧Keychain及默认Chrome不在本批范围。没有新增正式HTTP授权端点。
