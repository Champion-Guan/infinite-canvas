# 画布性能优化 - 应用说明

## ⚠️ 当前状态

由于项目使用严格的源码管理系统，直接修改 `.运行/3100源` 中的文件会导致装配系统检测到"未归并改动"并拒绝启动。

## 📋 正确的应用流程

要正确应用画布性能优化，需要按照以下步骤：

### 方式一：通过补丁系统（推荐给开发者）

1. **创建补丁文件**
   - 基于上游画布代码创建 Git 格式的补丁文件
   - 保存到 `上游适配/` 目录

2. **更新源码映射**
   - 修改 `上游适配/开发源码映射.json`
   - 添加新的补丁条目

3. **重新装配**
   - 运行 `npm run dev`
   - 系统会自动应用所有补丁

### 方式二：手动修改运行副本（快速测试）

如果只是想快速测试效果，可以：

1. **启动开发服务**
   ```bash
   npm run dev
   ```

2. **手动修改运行副本**
   - 等服务启动后
   - 直接编辑 `.运行/3100源/画布副本/web/src/pages/canvas/project.tsx`
   - 开发服务会自动热重载

3. **应用优化代码**
   - 在文件顶部添加导入
   - 修改节点渲染逻辑
   - 参考 `上游适配/画布性能优化补丁.tsx`

**注意**：这种方式的修改在下次重启时会丢失，需要转换为正式补丁才能持久化。

### 方式三：等待自动重载（当前方式）

1. **服务正在启动**
   - 开发服务会自动装配源码
   - 启动完成后访问 http://localhost:3000

2. **手动修改测试**
   - 服务启动后，手动应用优化代码
   - 测试性能改善效果
   - 确认无问题后再制作正式补丁
