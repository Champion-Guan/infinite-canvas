# 总览排序原生动效

## 原因与修改

总览排序入口原为普通按钮，虚拟列表直接更新定位坐标，因此按钮缺少按压反馈、列表换序直接跳变。

- 排序按钮使用 CSS 原生按压及背景过渡。
- 排序点击前读取当前可见项的实际呈现位置，排序立即更新；之后以 Web Animations API 播放 220ms 位移，新增可见项短暂淡入。
- 使用独立 `translate` 属性，保留虚拟列表原有 `transform: translateY(...)` 定位；仅为已挂载且处于视区的项播放，不创建额外全量卡片或图片副本。
- 任务列表与详情网格分别使用稳定 ID；再次排序先读取浏览器当前呈现位置，再取消旧动画。旧动画完成不能清理新动画，完成或卸载时释放填充效果。
- 开启减少动态效果时直接显示结果；原生动画不可用仍可排序。
