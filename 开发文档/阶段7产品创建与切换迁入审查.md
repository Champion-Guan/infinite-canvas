## 三、候选行为

### 1. 创建和命名

顶栏“新建产品”、空白页按钮、画布菜单创建都进入同一个操作出口。

- 默认依次创建“未命名产品1”“未命名产品2”…；扫描现有名称的最大编号加一，不用产品总数补缺口。
- 保留现有产品标题，不批量更名。重命名通过现有画布标题入口，胶囊同步显示。
- 使用现有独立产品 ID；忙碌时拒绝并发操作并禁用顶栏按钮。
- 新建后的保存如果失败，保留已经创建的产品和原产品，不自动删除、不跳页冒充成功。

### 2. 顶部胶囊

- 全局顶栏展示产品；按创建顺序排列，横向溢出滚动。
- 使用旧显示名截断规则和黄/绿/红任务状态。
- 正在查看的任务完成仍保留成功/失败色；重新进入对应产品后才确认通知。生成中的黄色始终不被确认隐藏。
- 已读标记放 SQLite 偏好，不写 localStorage。
- 摘要按节点数组和连线引用缓存；仅改变视区或其他无关字段时返回同一胶囊摘要，不触发顶栏内容更新。

### 3. 切换和独立保存

同一页面只运行一个 Zustand/SQLite 宿主，访问过的产品保留各自画布组件树。节点、连线、对话、背景、图片信息开关和视区按产品 ID 保存；选择、打开的节点编辑状态和撤销栈在当前页面保留实例期间保留。

切换顺序：当前产品请求真实 React 提交 → 验证非拖动/缩放/恢复中 → 保存完整产品快照 → SQLite 确认 → 保存目标选择偏好 → 导航。

- 保存期间又出现新编辑，拒绝本次切换并允许重试，不清空或回滚业务数据。
- 已有 500ms 视区保存定时器，仅在完整快照成功且仍是同一个视区时取消。
- 父级路由变化不得再次 hydrate 已恢复的产品；待恢复异步操作取消后不得回写过时页面。
- 隐藏产品停止接收全局键鼠输入；产品 Portal 使用显式 Context 容器；模态 open 加 active 门禁，防止隐藏页面锁住整个界面。
- 不修改全局 ReactDOM、Storage 或作者 DOM，不用 CSS 隐藏入口冒充产品切换实现。

模型配置、主题、素材库以及原本的全局侧栏设置仍是共享配置；“产品独立保存”不代表每个产品各建一个数据库或复制一份全局配置。
