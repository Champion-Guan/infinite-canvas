## 设计依据

已读取用户指定的 [Apple Design Skill](https://github.com/Champion-Guan/skills/blob/main/skills/apple-design/SKILL.md)，采用即时按压反馈、可中断过渡、稳定空间关系、明确状态、键盘操作及系统减少动态效果。Web 动效使用已有 Motion、Ant Design 和 CSS，不宣称是苹果原生动画。

保持原布局和功能位置。节点、连线动效迁移仍暂停。本轮不创建自动数据备份或源码快照；代码通过根模块、单功能接入补丁和 Git 差异定位。

## 检查覆盖及修复

| 范围 | 发现与处理 | 证据 |
| --- | --- | --- |
| 设置切页与保存 | 当前持久化筛选已能排除面板/页签状态；修正与 Zustand 正式存储类型不一致的问题，保留失败可重试及在途去重 | 真实 Zustand 连续 200 次纯界面切换：0 序列化、0 写入；实际设置十次切页无 429、无失败通知 |
| 参数初始化 | 两个 effect 会分别恢复记忆和补齐空值，后一个可能用旧空快照覆盖刚恢复的记忆 | 合并为一次提交；100 次重复渲染不写入，明确空值及“0”保留 |
| 参数记忆 | 重复保存相同参数仍进入偏好保存队列 | 内容相同直接返回；200 次重复值无新写入，真实改值保存一次 |
| 侧栏快切 | 旧关闭定时器会提前卸载后来一次关闭动画 | 重新打开取消旧计时器；关开关、21 次快速切换的真实状态库测试通过 |
| 侧栏动画 | 长缓动以及拖动时动画追赶影响跟手 | 改为 360ms、无回弹弹簧；拖动立即更新，减少动态效果为短淡变 |
| 侧栏拖动 | window 事件未处理 pointercancel、捕获丢失和卸载 | 使用指针捕获、按 pointerId 过滤、取消及卸载清理；拖动结束保存宽度 |
| 侧栏键盘 | 宽度手柄只接受鼠标 | 增加可聚焦分隔条，提供当前/最小/最大宽度；左右键每次 16px，Home/End 到边界 |
| 系统动态偏好 | 只关闭 CSS 无法覆盖 Motion 和 Ant Design | 增加共同动态偏好 Provider；减少动态效果同时传给两个组件库 |
| 首页轮播 | 自动播放缺少暂停控制，忽略减少动态效果，重排后播放状态可能不一致 | 增加播放/暂停、键盘方向键、32px 导航目标；交互后暂停；系统偏好即时停止并跳切；reInit 按当前选择恢复 |
| 顶栏按钮 | 按压反馈和触屏 hover 行为不统一 | 加入 80ms 按压反馈，hover 限定精细指针；减少动态效果时保留颜色反馈、取消位移 |
| 历史排序 | 脱离 document 调用浏览器 View Transition 方法可能失败；CSS 与 Motion 同时缓动 transform | 排序立即切状态，只使用已有列表位置弹簧；CSS 不再重复过渡 transform |
| 历史列表计算 | 每个任务重复遍历全部文件/失败项 | 按节点 ID 一次分组，复用结果；缩略图使用 lazy 和异步解码 |
| 历史总览 | 多图单列留白、完整提示词挤远下一张图，屏幕外详情也立即读原文件 | 按可用宽度自动并排并向下排放；提示词点击展开；视区内才读原图，卸载释放 URL |
| 历史选择 | 核对缩略图预览与勾选的分工 | 实际两张选择、第三张未选预览及取消勾选通过；预览不改变选择 |
| 更新状态请求 | 多入口并发读取相同状态；缓存隐藏产品也重复轮询 | 同一服务端口只共用在途 status 请求；完成即失效；隐藏产品及后台标签停止轮询，重见立即刷新 |
| 更新文案 | 安装确认仍声称会自动备份，与用户已关闭备份的要求不一致 | 改为核实保存和任务状态，再切换版本 |
| 自有模块边界 | 画布历史接口用 unknown 代替节点类型、消息接口缺少 loading；数个回调漏声明依赖 | 使用真实 React、Ant Design 和画布类型，补齐依赖；整批迁移预览显式接收订阅快照 |
