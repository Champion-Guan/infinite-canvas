# Excel工作簿提示词来源验收（2026-10-27）

## 问题与修改

设置原先使用 `/canvas/:id` 取得当前产品，再调用单产品来源 Hook，因此只可能显示当前产品，其他已上传的工作簿未被汇总。现在来源直接订阅现有工作簿集合，按工作簿 ID 自动派生全部模板。已上传文件无需重传；新导入发布工作簿后立即显示。名称默认使用「Excel提示词 · 文件名（不含扩展名）」，文件链接显示原始文件名，条数忽略空提示词。

不增加提示词持久化副本，不在读取、打开设置或切换页签时写来源。工作簿来源按稳定 ID 区分，同名文件互不覆盖。工作簿回收后退出来源列表，恢复后重新出现。来源改名、启停和删除偏好使用工作簿命名空间；旧单产品偏好仍保留。画布提示词内容和拖放 ID 继续按当前产品隔离，设置全簿查看条目不伪装成某个画布产品。
