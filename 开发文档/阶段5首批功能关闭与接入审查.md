## 1. 首批范围：D01、D02、D05

统一配置在 `扩展功能/产品配置/功能开关.ts`。三个功能开关默认关闭，入口、挂载、自动连接和执行边界读取同一份策略，不在多处各写一套布尔值。不新增设置 UI、运行时 URL 开关或数据库字段。

| 功能 | 实际调用链 | 拟关闭的边界 | 必须保留 |
| --- | --- | --- | --- |
| WebDAV | `AppConfigPanel` → `testWebdavConnection` / `syncAppDataToWebdav` → WebDAV HTTP；高层同步会合并画布、资产、生成记录 | 过滤设置页签；旧 `configTab=webdav` 回退渠道；高层同步在 hydration 和合并前拒绝；底层操作在目录创建、授权头和请求前拒绝 | `use-config-store` 中原有配置、配置导入导出、画布/资产/媒体/记录存储与完整上游源码 |
| 外部 Agent | `UserLayout` 总是挂载 `AgentPanel`，原始 store 的 `panelMounted=true`；`LocalAgentPanel` 内有客户 ID 初始化、URL/hash 引导、SSE 和画布快照订阅；顶栏会用已存 Token 自动连接 | 布局不挂载面板；普通顶栏和画布顶栏不显示 Agent 与状态；不自动连接，store 不开放面板/连接；不向 Agent 发布画布快照；共享 API 网络入口也拒绝 | 原配置和会话数据；插件宿主调用的 `applyAgentOps`、`applyCanvasAgentOps`、节点 SDK、画布撤销能力 |
| GA4 / 百度统计 | `main.tsx` 调用 `initAnalytics`；路由布局挂载 `AnalyticsTracker` 上报路由 | 禁止初始化和上报，即使构建环境有统计 ID；路由布局不挂载 Tracker | 作者源码、其他运行配置、作者 MIT 与前端标识 |

源码检查确认：

- WebDAV 目前是手动调用，未发现其自动同步定时器。不虚构一个“已停掉的自动同步任务”。
- 三项都没有独立页面路由；`/config` 仍承载必须保留的模型、渠道、偏好和本地存储。本批不删除 `/config`，也不为不存在的 `/webdav`、`/agent` 发明拦截。关闭旧 WebDAV 页签状态和直接服务调用，分别验证。
- 不能在 `useAgentBridge` 入口整体提前返回：插件也使用其 `applyAgentOps`。候选只在发布 Agent 上下文的 effect 内设门禁，保持 Hooks 调用顺序与共享操作原样。
- Agent HTTP 函数在错误捕获前拒绝禁用调用，避免被旧的 `catch → false/null` 吞成假成功。正常产品路径不再挂载发起这些调用的 Agent 面板。

这是功能关闭，不是打包体积精简。仍保留静态 import，相关模块可能继续包含在构建中；本批不声称已移除依赖、完全消除模块求值或隔离任意同源脚本。
