# 代理服务交接（2026-10-25）

旧项目 `http://localhost:3000` 保留运行，仅关闭本地代理、网络代理；原代理状态文件两个开关均为 false，原核心已退出。新项目默认从 3000 查找空闲端口，当前自动使用 `http://localhost:3001`，沿用原工作区 `931e75c3-5f4d-4152-ab4b-6b63478fb1c0`。

## 实现

- 根目录 `扩展功能/网络代理/` 按核心定位、旧配置接续、本地转发、域名解析、节点诊断、前端请求和本地面板拆分维护；作者代码以 10 份独立中文接线补丁导出到 `上游适配/`。
- 新配置的本地代理、网络代理默认开启；主动关闭后持久保存，冷重开保留选择。没有网络配置时显示等待配置，不伪报核心已运行。
- 首次接续本用户原订阅与缓存配置到 SQLite 凭据保管；不向页面读回订阅、节点密码。已有新代理记录时不重复接续、不覆盖用户开关。
- 复用本机现用 Mihomo，校验指纹后放到稳定的应用支持目录。仅监听 loopback，不修改系统网络代理、不接管其他进程。
- 本地转发走现有页面授权与业务会话，不再让 Mihomo 的端口承担浏览器 CORS 转发，不再展示 npx 手动启动命令。图片、文本、视频、音频、自定义渠道请求、WebDAV、图片及媒体缓存、媒体下载均接到显式请求适配器，不覆盖全局 fetch/axios。
- 网络启用后经受管核心请求；核心未就绪时明确失败，不暗中直连或重发生成。取消信号传到本机请求，转发结束释放路由租约。
- 系统 DNS 返回 198.18/15 Fake-IP 时，经受管代理向固定 Cloudflare DoH 服务解析真实公网 IPv4；仍固定目标 IP、校验证书、拒绝私网地址。
- 实际连接诊断按本次 CONNECT 的源端口和目标 IP 匹配核心连接链；未观测到时明确显示未确认，不能把配置选择项冒充实际节点。全节点测速排除内置 PASS/REJECT 策略。
- 本地转发正文和响应均沿用 32MiB 限制，不落盘；原代理目录容量保护、日志轮换、自动备份关闭等磁盘治理保持。
