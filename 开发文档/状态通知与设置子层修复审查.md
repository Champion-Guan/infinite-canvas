## 问题及预期行为

真实保存 ACK 丢失时，长错误文案的“本机保存状态”会挡住“重试任务确认”。现有保存重试仍能恢复保存并自动继续确认，账本与图片没有丢失；该缺陷属于提示布局。候选让两个现有 React 提示共用自然流通知区，任务确认在上、本机保存在下，保留原文案、按钮、任务作用域和事件流程。长文案及窄窗口采用共同的可滚动区域，避免两个组件各自使用固定 bottom 值。通知区由 React ref/context 和 createPortal 提供，不查询或修改作者 DOM，不订阅额外全局存储事件。

1440×1000 下旧渠道编辑抽屉从顶栏下方 y84 开始、高916；当前新版从 y0 开始、高1000。模型选择旧 y377、高330；当前新版 y337、高326。候选让两者使用九文件前置已提供的真实设置视区，通过 Ant Design 官方 getContainer、rootStyle/styles 接口定位；模型列表最大高度改以该视区的 62cqh 计算。独立调用无视区时继续使用组件原有全页行为。

本批只处理定位与提示叠放。模型选择现有内容高度四像素差异、完整旧代理和 Fallback 内容等没有被本候选证明一致，后续实测仍需如实记录。
