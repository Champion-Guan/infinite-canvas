# Web客户安装与升级

仓库固定为`Champion-Guan/infinite-canvas`。当前公开预览版为[Web 2.0.0-beta.10](https://github.com/Champion-Guan/infinite-canvas/releases/tag/web-v2.0.0-beta.10)，包含保存与工作簿切换优化、共享主干连线、图片详情下载、密钥脱敏、更新进度及配置补齐状态修复。沿用原可信签名，仅支持Apple Silicon macOS；默认从3000端口启动，占用时顺延。公开资产下载、签名、576项库存与现有工作台更新检查已通过；本轮未做跨Mac或beta.9到beta.10真实安装切换，详见[第十预览版发布验收](第十预览版发布验收20261027.md)。下文的早期记录保留供追溯。

## 客户使用

1. 下载Release中的`Web-v2.0.0-beta.10-macos-arm64.zip`（展示标签为中文），解压后双击`安装工作台.command`。安装器联网取得本Release的签名清单，核验固定可信公钥、全部库存、Node和系统助手。Source code ZIP不是客户安装包。
2. 双击`启动工作台.command`，按输出的实际地址打开。包内带Node，无需安装npm。3000被占用时自动顺延，不接管或强杀占用进程。旧beta.3管理器主持的首次升级仍暂用3100；新版管理器下一次正常冷启动即使用自动端口策略。
3. 在保存旧数据的同一浏览器中打开旧工作台实际地址的`/local-app/port-migration`，选择“导出当前浏览器完整备份”。在新版“设置→旧版整批迁移”选择备份，可另选补充配置JSON；检查差异后一次合并全部产品、Excel工作簿、回收快照、画布引用素材和普通配置，等待“整批迁移已保存”。不用逐个导出产品或重新导入每个Excel。重复导入不会重复新增，原数据与完整备份均需保留。详细操作及范围见[旧版整批迁移与配置验收20261024](旧版整批迁移与配置验收20261024.md)。API密钥、WebDAV密码、请求脚本及旧工作区凭据绑定不自动迁入；目标已有凭据保留。旧`/local-secure-api/`转发地址也不含真实服务端点，需要补充配置或手动填写，协议默认地址不代表原渠道。
4. 后续在设置→软件更新检查、下载并暂存更新；确认画布已保存、任务已结束，再确认准备安装并关闭工作台页面。管理器重新验证包与身份、检查页面和持久任务、确认工作区身份后切换。其他网站可继续使用。
5. “待核实”任务只有在渠道确认结束后，才能按实际结果处理；没有结果时使用“已结束且没有结果”核实入口，保留记录和审计，不能为升级删除任务或重新生成。

GitHub会净化中文资产名，远程固定为`Web.json`、`Web.sig`和`Web-v版本-macos-arm64.zip`；本地清单、ZIP及签名描述保留中文。安装器只接受固定仓库`web-v*`预发布的匹配签名资产。

安装目录：`~/Library/Application Support/AI-Workbench-Web安装`；个人数据：`~/Library/Application Support/AI-Workbench-重建版/工作区`。版本目录与SQLite、媒体、凭据分开。升级不清空数据；Origin/schema不匹配则拒绝就地升级。目标启动失败时保留或恢复旧版本。

若出现“保存尚未确认”，编辑仍保留在当前页，先使用“重试未确认保存”并等待“已保存”，不要刷新或关闭。beta.4修复了受控会话续期响应丢失后的恢复缺口，并增加保存阶段与错误码诊断；未知保存回执、版本冲突仍保留保护。beta.3本机首装首次失败的具体根因未捕获，不能认定与该续期缺口相同。崩溃遗留安装锁也尚无自动恢复入口，不可直接删除锁强启。

## 开发、构建与签名

根`扩展功能/`是业务唯一来源，根`上游适配/`保存锁定作者提交的有序单功能补丁；`.运行/`是生成输入和私人证据，不提交。不要将运行副本变成第二业务来源。

在发布检出、macOS arm64及Node24环境执行：

```sh
npm run web:test-update
npm run stable:runtime -- arm64
npm run web:build -- output/stable-runtime/arm64
```

构建在`.运行/Web客户包/构建-*/`生成中文ZIP、逐文件库存及`构建结果.json`。前后端使用锁依赖，从作者固定Git SHA取源码；不复制工作簿、数据库或已安装助手。构建不打开工作台端口或Keychain。输入变化即失败；脏树候选`releaseReady:false`，不允许签名。

在干净固定提交上构建并按`开发文档/Web发布版本.json`建立匹配标签，所有者本机签名/发布命令：

```sh
node 开发工具/签名Web客户包.mjs /绝对路径/构建结果.json /既有加密签名备份目录 RELEASE-WEB-PREVIEW
node 开发工具/发布Web预览版.mjs /绝对路径/构建结果.json RELEASE-WEB-PREVIEW
```

入口限定GitHub所有者Champion-Guan（87700227）、干净提交和标签，复用原固定公钥及Keychain保护的原加密签名材料。不得换密钥、降低验签或将私钥放参数/聊天/环境。先上传Draft并下载复核，再公开预发布，不替换Stable。已发布beta.3至beta.6标签及签名包固定；后续文档提交不覆盖它们，代码修复另发新版本。
