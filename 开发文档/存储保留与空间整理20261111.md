# 存储保留与空间整理

日期：2026-11-11。状态：已完成当前开发服务的设置、预览、保存与刷新验收；真实存量删除和数据库压缩未执行。

## 用户入口与文案

设置中的本机存储增加自动清理开关、保留天数、到期内容扫描、存量整理预览、确认清理、最近整理记录，以及单独的数据库内部空间释放入口。

| 原名称 | 用户看到的名称 | 说明 |
| --- | --- | --- |
| 历史及未发布分片 | 旧版保存记录 | 区别于图片生成历史，扫描确认不再使用后才整理 |
| 当前未引用的保留媒体 | 暂时未使用的文件 | 重新使用后继续保护，按期限整理 |
| 跨分类共享内容 | 多处共用的文件 | 仍有使用处时保留，容量不重复计算 |
| 其他扩展数据 | 工作台运行记录 | 任务状态、保存确认与设置，系统管理 |
| 其他媒体 | 其他文件与恢复记录 | 包含其他上传文件和任务临时恢复内容 |

默认页面隐藏存储分片数、媒体块数等内部计数。WAL、SHM 等技术信息收进默认折叠的“技术明细”。每类显示用途和保留状态；产品及 Excel 回收站的永久删除入口改为“清空”，保留影响说明。

实页复核后，清理预览也改为按用途展示容量：旧版保存记录、暂时未使用的文件、已保存结果的恢复文件。不再把底层存储条目数作为用户文件数显示；回收记录与待恢复任务继续显示项数。

## 保留范围

- 自动清理默认开启，默认 90 天，可设置为 7 至 365 天；关闭后已准备的自动清理也不能继续执行。
- 工作台打开、页面可见且空闲时检查；正在保存、正在生成或刚发生交互时延后。关闭工作台期间不运行，恢复打开后补做；成功后当天不重复执行。
- 活跃文档引用、用户保留素材、较新的产品或 Excel 回收记录、待恢复任务及其所属产品持续保护。画布内节点回收批次继续作为画布引用保留，不由本入口直接改写其撤销历史。
- 新媒体失去最后一个数据库引用后记录闲置起点；重新引用或重新上传后重新保护。旧媒体及旧版保存记录从首次确认闲置起算，不使用文件修改时间推断闲置年龄。
- 生成任务只有已核验画布保存、且保留期已满时，才移除原始响应内容。任务 ID、请求摘要、成功状态和原响应摘要继续保留；原 ID 重试不会再次调用渠道，旧卡片收据仍可确认。
- 生成任务的响应清理中断时，已到期媒体标记持久保留；后续扫描可继续回收，不重新等待 90 天。文件若被其他记录引用，则继续保留。
- 存量整理可提前回收已确认闲置的媒体、旧版保存记录和已保存任务响应；产品与 Excel 回收内容仍须满足保留期限。

## 存储与删除边界

生成响应中的已知图片字段拆成内容寻址媒体，响应保存原始文字片段和图片引用。交付给浏览器时恢复为原始字节，并继续核对 SHA-256 和长度。图片之后上传到画布时复用相同字节，不再把 Base64 大图与原图重复存储。无法识别的响应继续沿用原保存方式。

清理接口使用既有本机 Origin、短期会话和 CSRF 校验。扫描和删除共用原写入队列；扫描验证业务记录、媒体目录及引用，旧分片还须满足内容寻址身份和已知格式。预览最多保留十分钟，删除前再次核对业务版本、任务签名和实际引用；不会扩大到扫描后新增的闲置文件。

回收站清理沿用原 Zustand 状态、保存队列和持久恢复清单，只处理预览中列出的到期条目。其他回收项、恢复后的产品及共用素材保留。恢复清单改为字符串保存，兼容早期对象清单，避免中断清理阻止下次启动。

普通清理先释放数据库内部空间，供后续保存复用。用户可单独确认“释放到磁盘”，再进行数据库压缩；沿用写入余量检查，为临时写入预留空间，期间保存进入原队列。自动清理不会反复压缩整个数据库。
