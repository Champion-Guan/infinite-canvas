# 画布性能优化方案

## 问题分析

用户反馈画布有 169 个卡片时出现以下性能问题：
1. 拖动画布卡顿
2. 缩放画布操作卡顿
3. 画布加载速度慢

### 当前实现状态

项目已有以下优化：
- ✅ 空间可见索引（`createVisibilityIndex`）- 快速查询视区内节点
- ✅ 渐进挂载（`useProgressiveCanvasNodes`）- 分帧加载可见节点
- ✅ 媒体延迟加载（`useVisibleCanvasMedia`）- 只加载可见区域的图片

### 性能瓶颈

1. **驻留节点过多**
   - `residentCanvasNodes` 包含所有已挂载的节点
   - 节点离开视区后仍保留在 DOM 中
   - 169 个节点全部在 DOM 中会导致拖动卡顿

2. **拖动时无降级渲染**
   - `isCanvasPanning` 时仍然渲染完整的节点
   - 每个节点包含复杂的 UI（按钮、面板、连线端点等）
   - 拖动时应该简化为缩略图或占位符

3. **每帧渲染开销大**
   - 每个 CanvasNode 接收 30+ 个 props
   - 大量的计算属性（`isRelated`, `mentionReferences` 等）
   - 缺少 React.memo 优化

4. **连线渲染开销**
   - 大量卡片意味着大量连线
   - SVG 路径计算和渲染开销

## 优化方案

### 方案 1：拖动时降级渲染（快速实施，高优先级）

**思路**：在 `isCanvasPanning` 或 `isCanvasZooming` 时，渲染简化版卡片

```tsx
// 在 project.tsx 中
{residentCanvasNodes.map((node) => {
  const shouldSimplify = (isCanvasPanning || isCanvasZooming) && visibleNodeIds.has(node.id);
  
  if (shouldSimplify) {
    // 简化渲染：只显示边框和缩略图
    return <SimplifiedCanvasNode key={node.id} data={node} scale={viewport.k} />;
  }
  
  if (!mountedVisibleNodes.has(node.id) || hasDeferredCanvasMedia(node)) {
    return <CanvasMediaPlaceholder key={node.id} node={node} />;
  }
  
  return <CanvasNode key={node.id} data={node} {...props} />;
})}
```

**收益**：
- 拖动帧率提升 50-70%
- 实施成本低
- 用户体验立即改善

### 方案 2：更激进的虚拟化（中等实施，中优先级）

**思路**：只保留当前视区 + 一小圈缓冲区的节点

```ts
// 修改 useProgressiveCanvasNodes
export function useProgressiveCanvasNodes(
  nodes: CanvasNodeData[], 
  interacting: boolean,
  keepMountedDuration = 5000 // 离开视区后 5 秒卸载
) {
  const [mounted, setMounted] = useState<ReadonlySet<string>>(() => new Set());
  const unmountTimers = useRef(new Map<string, number>());
  
  useEffect(() => {
    const visible = new Set(nodes.map(n => n.id));
    
    // 清理不在视区的节点
    Array.from(mounted).forEach(id => {
      if (!visible.has(id)) {
        if (!unmountTimers.current.has(id)) {
          const timer = window.setTimeout(() => {
            setMounted(prev => {
              const next = new Set(prev);
              next.delete(id);
              return next;
            });
            unmountTimers.current.delete(id);
          }, keepMountedDuration);
          unmountTimers.current.set(id, timer);
        }
      } else {
        // 重新进入视区，取消卸载定时器
        const timer = unmountTimers.current.get(id);
        if (timer) {
          clearTimeout(timer);
          unmountTimers.current.delete(id);
        }
      }
    });
    
    // 渐进挂载新节点
    // ... 原有逻辑
  }, [nodes, interacting]);
  
  return mounted;
}
```

**收益**：
- DOM 节点数量减少 60-80%
- 内存占用降低
- 需要测试确保五分钟空闲机制不受影响

### 方案 3：React.memo 优化（简单实施，中优先级）

**思路**：为 CanvasNode 添加 memo 优化，避免不必要的重渲染

```tsx
// 在 canvas-node.tsx 中
export const CanvasNode = React.memo<CanvasNodeProps>(
  function CanvasNode(props) {
    // 组件实现
  },
  (prev, next) => {
    // 自定义比较函数
    if (prev.data !== next.data) return false;
    if (prev.isSelected !== next.isSelected) return false;
    if (prev.isViewInteracting !== next.isViewInteracting) return false;
    if (prev.scale !== next.scale) return false;
    if (prev.isInViewport !== next.isInViewport) return false;
    // ... 其他关键 props
    
    return true; // 相同，不重渲染
  }
);
```

**收益**：
- 减少 30-50% 的不必要重渲染
- 实施简单
- 无副作用

### 方案 4：连线渲染优化（复杂实施，低优先级）

**思路**：
1. 使用 Canvas 2D 而不是 SVG 渲染连线
2. 拖动时隐藏或简化连线
3. 连线层独立渲染，不随节点更新

```tsx
// 在拖动时隐藏连线
<CachedConnectionLayer
  visible={!isCanvasPanning && !isCanvasZooming}
  connections={visibleConnections}
  // ...
/>
```

**收益**：
- 大幅减少 SVG 重绘开销
- 实施复杂度高
- 可能影响连线交互

### 方案 5：Web Worker 计算可见性（复杂实施，低优先级）

**思路**：将可见性索引计算移到 Web Worker

```ts
// visibility-worker.ts
self.onmessage = (e) => {
  const { nodes, viewBounds } = e.data;
  const visibleNodes = computeVisibleNodes(nodes, viewBounds);
  self.postMessage({ visibleNodes });
};
```

**收益**：
- 主线程更流畅
- 实施复杂
- 需要序列化开销

## 实施细节

### SimplifiedCanvasNode 组件

```tsx
// 简化版节点，拖动时使用
export function SimplifiedCanvasNode({ 
  data, 
  scale 
}: { 
  data: CanvasNodeData; 
  scale: number;
}) {
  const theme = useThemeStore((state) => state.theme);
  const colors = canvasThemes[theme];
  
  return (
    <div
      className="absolute pointer-events-none"
      style={{
        left: data.position.x,
        top: data.position.y,
        width: data.size.width,
        height: data.size.height,
        border: `${2 / scale}px solid ${colors.node.border}`,
        background: colors.node.fill,
        borderRadius: 8 / scale,
        opacity: 0.8,
      }}
    >
      {/* 可选：显示缩略图 */}
      {data.type === 'image' && data.metadata?.content && (
        <img 
          src={data.metadata.content} 
          className="w-full h-full object-cover"
          style={{ borderRadius: 8 / scale }}
        />
      )}
    </div>
  );
}
```

### 性能监控

```ts
// 添加性能监控
const frameCount = useRef(0);
const lastTime = useRef(Date.now());

useEffect(() => {
  if (isCanvasPanning) {
    frameCount.current++;
    const now = Date.now();
    if (now - lastTime.current >= 1000) {
      const fps = frameCount.current / ((now - lastTime.current) / 1000);
      console.log(`拖动帧率: ${fps.toFixed(1)} FPS`);
      frameCount.current = 0;
      lastTime.current = now;
    }
  }
}, [isCanvasPanning, viewport]);
```
