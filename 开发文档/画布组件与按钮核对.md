# 画布组件与按钮核对

本文记录旧项目 3000 与当前开发版 3100 的首轮画布现场及源码对照。页面入口为既有 Chrome 标签页，没有建立隔离测试工作台或改写两端业务数据。已现场查看主画布菜单、批量菜单、底部工具栏、小地图、外观面板、节点信息、生成历史空状态，以及本次修复涉及的 Excel 来源、提示消息、产品胶囊遮罩和 Modal 关闭后点击。此结果是有边界的迁移核对，不代表所有画布状态、尺寸、主题及真实媒体业务流程均已通过。

文本结果先保存原产品、原节点与槽位任务身份再提交；收到响应后，正文、成功槽位和收据一并保存，确认失败保留原内容与原任务，不自动发起新请求。独立保存确认现在识别图片、文本及参数卡；确认后仅清理对应成功槽位的保存错误，不清除其他失败项。当前文本通道使用非流式完整响应后显示，旧版逐字流式效果尚未等价迁入，不将它标记为已完成。

主题校准随原任务保存完整输入快照，恢复响应时按收据任务号匹配；当前正文优先于Excel原文，完整正文用于并发修改比对。缺失原任务输入时拒绝套用，避免旧响应覆盖新输入。

临时创建的参数卡、连接及自动预览已撤销，尺寸测试配置卡也已撤销，3100原17条提示词保持；此前审核刷新验收用的配置卡移入可恢复的节点回收站。旧3000临时配置卡已撤销，没有将两端数据互相覆盖。

## 生成历史下载入口说明

入口位于左侧「生成历史」页签顶部工具条，和「排序」「重试」「选择」同一行，最右侧为「下载」。当前 3100 空历史下该按钮保持可见但禁用；选择单个或多个历史文件后会打包下载，非选择模式会打包所有有效成功文件。空历史时没有文件可用于实测文件名、ZIP 内容、失效缓存跳过及浏览器落盘行为，所以这些仍是待验收项目。旧 3000 的空历史界面隐藏了该按钮，这解释了空状态下看起来像“没有下载”的差异。
