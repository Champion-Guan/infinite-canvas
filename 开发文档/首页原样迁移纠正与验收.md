# 首页原样迁移纠正与验收

## 纠正目标

用户重建项目是为了整理结构、保留上游更新能力，**不是重新设计界面**。上一轮以新 React 布局重画首页，即便逻辑测试通过，也不符合原样迁移要求。历史报告只证明当时测试范围，不再作为视觉一致的完成依据。

后续所有旧业务迁入必须先追踪真实实现、资源、样式、状态和事件依赖，迁入原实现，仅适配资源地址、模块边界和数据/事件出口。禁止凭截图另写简化功能。需要改作者核心接入口时仍须提供具体差异并单独批准。此规则已写入 `AGENTS.md`。
