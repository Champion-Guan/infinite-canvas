# 统一动效底层规范验收

## 底层规则

已新增 `开发文档/基础交互动效规范.md`，并在 `AGENTS.md` 最底层产品原则末尾设为所有新设计与后续调整的约束。范围包括面板、下拉、页签内容、横条弹簧、开关、按钮与选择状态、提示、主题及异步反馈，同时要求即时响应、可打断、键盘语义、减少动态效果和资源清理。

## 本轮代码

- 设置窗口移除 `ant-fade` 特例，恢复 `AppleModal` 默认原生窗口进退场。保留设置触发器边界，重复点击仍能关闭；不再通过导航重挂载或改变窗口动画纠正横条。
- `统一页签横条.ts` 为原生 Tabs、左侧页签及 Agent 提供同一布局坐标测量和胶囊弹簧播放器。目标变化时一次采样，由 Web Animations API 播放 transform；快速改向保留位置、宽度与速度。
- 横条首帧和布局变化直接就位；窗口及按钮缩放不参与布局坐标。隐藏产品停止驱动，卸载清理观察器和监听。
- 原生 Tabs 内容主题时长对齐自定义双向淡变的 180ms。
- Excel 提示词工具条的手绘开关替换为 Ant Switch small，沿用原持久键和布尔值，移除旧手绘轨道 CSS。其他开关继续复用现有 Ant 组件和中性深浅色主题。
- 主题入口继续复用已有 `AnimatedThemeToggler` / `runThemeTransition` 圆形扩散，400ms；下拉继续沿用原生 Dropdown / Select / Popover。

## 实页证据

沿用现有 Chrome、`http://localhost:3000` 和用户工作区，没有新建工作台或触发生成任务。

- 设置打开时观察到 `ant-zoom-appear` / `ant-zoom-appear-active`，窗口从 scale 0.2 向 1 展开。渠道横条中心偏差约 0.001–0.004px；重新打开“提示词来源”时偏差约 0.07–0.34px，横条与页签共同随窗口缩放，没有导航重建后的跳位。
- 左侧从画布切到回收站，横条 transform 中的 x 从约 40.8→146.7→185.7 向目标 264 收敛，最终中心偏差约 -0.023px。
- 原生设置横条从渠道向软件更新移动，采样 x 约 171.5→446.3→540.4；中途反向返回渠道时从当前约 557.8→494.8→377.9 续接。未使用 CSS 匀速过渡，计算后的弹簧轨迹由浏览器播放。
- 提示词来源的四个可见开关均为原生 `ant-switch-small`，约 28×16px，保持开启。玩偶产品 Excel 视频导入开关为同一原生组件、约 28×16px，保持关闭；未点击改变这些业务状态。
- 顶栏主题入口浅色→深色→浅色，记录到同一个 400ms 浏览器主题过渡；恢复浅色后过渡标记已清理。
- Excel 下拉使用原生 `ant-slide-up`，连续 Enter 可在展开途中收起，最终 aria-expanded=false；没有切换工作簿。
- 验收后恢复原蜡烛产品、画布页签及浅色主题。
