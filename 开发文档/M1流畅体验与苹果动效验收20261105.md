# M1 流畅体验与苹果动效

日期：2026-11-05。目标设备在本机确认为 MacBook Air M1（MacBookAir10,1）、8 GiB 内存、arm64；本机可用磁盘当次为 94 GiB。用户体验至上是产品、性能与交互决策的根本标准，不因性能数字、视觉效果或动画完整度牺牲正确性、清晰度、可访问性、操作反馈或数据保护。

## 修复与优化

- 生成历史原文件预检改为读取 `image_files` 与 `media_files` 两份键索引，不再为历史列表逐个读取、解码和传输原图。暂时无法读取索引时保持未知状态，并明确提示稍后在预览/下载时重试，不把存储错误误报为素材丢失。
- 生成历史总览改为按滚动视区读取和释放预览原图；长历史详情和列表行采用原生 `content-visibility`，固定估算尺寸以降低未显示内容的布局/绘制工作。
- 共享连线流动点在全部高亮段上的总数限制为 96。焦点网络过大时降低点密度，超过安全预算时只保留高亮连线，保持原拓扑、同步速度、命中区和可访问名称。无高亮时不构造数据流网络；复杂空网络和无路线调用在昂贵拓扑扫描前返回。
- 后台标签页卸下循环连线粒子；系统要求减少动态效果时不启动粒子。详情图离开总览视区会撤销临时 Blob URL，并在重新进入时按需读取。
- 在线更新和安装进度统一使用单在途、完成后再计时的可见页面轮询；产品页签和更新设置页签隐藏时停止读取，慢请求不再被 interval 重叠调用。
- 按 Apple Design 原则引入临界阻尼控制弹簧和共享按钮适配器。画布拖动、平移、缩放继续 1:1 跟手，不增加惯性等待；设置面板切换使用短、可逆的轻量淡入，不堆叠隐藏页签内容的进出动画。移除节点结算和历史重放的滤镜/模糊逐帧变化，避免额外合成成本；不再常驻声明 `will-change`。
- 产品参数、历史操作、Excel 弹窗与菜单、设置 Ant Design 按钮、画布工具栏 Ant Design 按钮共用即时按压反馈。减少动态效果时替代反馈为轻量透明度变化或静态状态，禁用状态不缩放。
- 商品提示词失效时点击单卡生成或批量执行，只让对应已有常驻提示框进行一次递减左右反馈，不新增重复 message，不提交请求、不改画布；框未挂载时仍显示原具体错误。此项通过真实 localhost 交互验证。
- 修复提示词翻译 Hook 多余依赖问题；原 React Hooks/模块检查中 243 个自有 React 模块与 787 个 JavaScript 模块无报告问题。

## 指标边界

上述结果证明指定代码路径、测试矩阵和当前会话的交互符合预期，不代表遍历了作者仓库全部源代码，也不等同于长时间、全画布、系统级的 CPU/内存/帧率实测。当前未作持续数小时的 Chrome RSS/JS heap、连续拖拽帧时间分布、完整真实媒体库打开时间或热降频测试；没有据此声称固定的“60 FPS”、内存降低比例或整机永不卡顿。目标设备剩余可用内存会被桌面、浏览器其他标签和代理等进程共同影响。
