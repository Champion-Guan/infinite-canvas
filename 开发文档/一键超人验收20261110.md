# 一键超人

- 所有有图片内容的画布卡片，悬浮工具栏固定增加闪电图标入口“一键超人”，包含换语言、换颜色、增加尺寸标注。使用原生级联菜单，在对应子项旁填写要求，输入框右侧按钮直接发起单张图片编辑生成。
- 尺寸标注用于图片中的产品主体：添加尺寸线、延长线、箭头和数值单位，并对应主体部位和测量方向。仅使用用户填写的数据，不根据图片比例猜测其他尺寸。
- 图标与文字采用同一个垂直居中的行容器。三项菜单锚定“一键超人”按钮上下方，宽度固定156px；每项分别使用自己的原生Popover编辑框，锚定对应菜单项右侧，输入保持各自草稿。编辑框按内容自然增高（2至5行），背景由原生Popover完整包裹输入和生图按钮。边缘复用原生避让，支持键盘展开、外部关闭及输入区 Escape 关闭。
- 操作读取当前图片，独立创建结果卡和来源连线。复用原图片工具任务、驻留保护、模型配置门禁、请求登记、结果落盘和保存流程。结果可使用原重试入口；输入为空、图片失效或画布不活跃时不发请求。
- 快捷工具设置包含“一键超人”，默认显示；旧设置补入新工具，明确隐藏后不会在刷新时重新勾选。选项的勾选框、图标及文字统一居中。
- 工具栏在卡片上方保留14px间距；只有外侧位置触及顶部标题区时才移入可见图片顶部。使用原视区绘制回调实时同步平移、缩放，不额外创建逐帧循环，工具栏保持48px屏幕高度。
- 原画布容器使用overflow:hidden时，浏览器可在输入框获得焦点后滚动该容器，造成图片与外层工具栏偏移。改用overflow:clip禁止这种隐藏滚动，用户平移和缩放继续通过既有视区控制器处理。
- 一键超人读取当前图片实际交付像素宽高，写入请求尺寸、提示词及结果卡快照；首次和重试均使用同一目标。现有交付服务可等比例缩放到精确尺寸；上游比例不符时拒绝回写，保留原图片并明确报错，不拉伸或裁切成目标尺寸。旧的已生成方图不自动重新生成。
- 63项专项及相关回归通过，覆盖主体标注规则、单图引用、并发快照隔离、保存与失败恢复、像素尺寸交付、严格尺寸回写、配置兼容及实时工具栏定位。源码装配与完整 TypeScript 检查通过。
- 当前 localhost:3000 实页验证原图工具栏在图外与顶部遮挡后图内切换、缩放后48px高度保持；自定义工具勾选取消、保存、刷新恢复及重新启用；输入要求与禁用/启用状态。未提交收费生图，真实模型对文字、颜色与主体尺寸线的遵守程度尚未验证。
- 最终实页测量：三项菜单锚点与按钮左侧误差小于1px；菜单宽度约156px，独立编辑框约344px，水平间距8至11px，无面板相交。颜色输入4行后高度约97px，语言与尺寸输入2行约53px；切回后草稿保留，语言框重复打开的纵坐标一致。输入和生图按钮都在Popover背景边界内。
- 焦点修正后画布scrollTop保持0；图外时工具栏底部与图片内容顶部相距约14.6px，顶部遮挡时工具栏位于画布顶部64px以下。勾选框与图标中心测量一致，文字中心误差小于0.01px。
