# 版本历史来源修复验收

## 问题与修复

beta.27已于2026-11-08公开，但版本弹窗将在线说明与从画布`CHANGELOG.md`注入的本地记录拼接。该文件来自`画布变更记录.md`，保留`Unreleased`开发草稿及作者`0.x`历史，因而在客户版本历史中出现“未发布”。

当前版说明改用`Web更新说明.md`，既有历史改用从固定仓库公开Release同步的`Web版本历史.json`。初次修改只接入当前版，未保留用户需要的旧版时间线；已在同轮补齐全部21个实际已公开的Web客户版本，从beta.27至beta.3倒序显示。实际未发布的缺号不补造，草稿和作者历史不混入。

构建复用原有分类解析器和语义版本比较；当前版去重，旧版非分类说明保留原文。离线也提供完整历史，运行时不新增GitHub轮询。发布前通过`同步Web版本历史.mjs`刷新历史，说明版本、历史身份和重复版本在构建前校验；两份说明及读取模块纳入977项发布输入指纹。

## 已验证

- 固定仓库实际返回21个非Draft Web Release，全部同步入离线历史；没有更改远程Release、标签、签名或旧安装包。
- 12项定向检查通过，覆盖分类和日期、版本不匹配、开发草稿、空说明、重复版本、Beta/Stable筛选、旧说明原文、去重、语义排序及下一版本构建时保留旧历史。
- 生成输入653文件、2103引用一致；开发前端构建成功，原工作区及localhost:3000保持。
- 当前Chrome真实页面刷新后，时间线实际有21项，包含beta.26、beta.25和beta.3；“未发布”及作者0.19.0不再出现。
- 页面当时提示本地代理不可用，在线更新信息读取失败；完整历史仍可显示，实际验证了离线展示。未改变用户代理配置。
- 已滚动到beta.26并记录原页面截图：`.运行/验收截图/客户版本历史已恢复.png`。

## 边界

本次修复已在当前开发工作台生效，未重发或覆盖已签名的beta.27客户包。后续客户构建使用同一修复入口。当前问题属于日志来源与展示，不代表beta.27未发布，也不替代客户实机升级和网络下载验收。

原画布开发记录及上游待办继续保留，未改动其历史文字。该修复不新增生图、模型、存储或画布编辑能力，原功能待办无需迁移；本记录补充版本说明的实际验收结果。
