# 滚动区域恢复默认间距

按用户最新要求撤回之前的滚动条专用留白，恢复各组件原有间距和滚动条样式。

## 修改

- 取消历史滚动标记类的统一样式：不再强制左右 18px、双侧稳定滚动槽、横向列表额外上下留白或 6px 滚动条。历史标记仅保留为无样式标记，作者原有工具类正常生效。
- 设置面板、模型选择、技能面板的滚动 body 恢复接入留白前的样式，经补丁维护器生成三个局部接入补丁。
- 恢复 Excel 下拉、产品回收站、模型排序、图片详情、历史总览、提示词优化、设置浮层、关系选择及状态通知等自有区域的原有间距。
- Excel 导入区原本的 `scrollbar-gutter: stable` 保留；不再改为 `stable both-edges`。作者 `.thin-scrollbar` 的 4px 样式未修改，与锁定上游提交一致。
- 不更改滚动、虚拟化、键盘、数据保存、面板开关及动画逻辑。

## 验证

- 来源检查：640 文件、2029 引用、404 接入补丁，一致。
- 体验/Hook 检查通过；有界 TypeScript 检查通过。
- 生成历史、虚拟列表、原生浮层、提示词优化、连线交互和菜单相关 56 项现有测试通过。
- 当前 `http://localhost:3000` 实页：画布侧栏左右留白由 18px 恢复 8px，`scrollbar-gutter` 从 `stable both-edges` 恢复 `auto`。
- 历史虚拟列表左右 12px、无双侧滚动槽，横向无溢出。PageDown 实际滚动至 363.89px，Home 返回 0，当前画布显示已保存。
- 设置 body 为左 0px / 右 12px、gutter 为 auto，无横向溢出。Excel 下拉宽度 250px、左右 7px、gutter 为 auto，无横向溢出。
- 未修改用户内容或配置，未调用模型生成。
