# 弹出面板点击外部关闭

## 行为与范围

- 应用内 Modal、Drawer、Ant Design Dropdown/Popover/Select 统一支持点击外部关闭。保留原组件、焦点逻辑与 CSS 退场动画，不增加遮挡画布的透明覆盖层。
- 对下拉和浮层使用窗口捕获阶段的 `pointerdown`，覆盖画布平移取消兼容鼠标事件的情况。多个打开浮层共用一个监听，全部关闭后注销。
- 同时识别触发按钮、面板根和通过 React Context 关联的子 Portal。点击嵌套选项保留父面板；点击工作区遮罩范围以外的顶栏也能取消最上层弹窗/抽屉。
- 自定义右键菜单、连线创建面板、引用候选菜单和卡片下方编辑器也接入。编辑器关闭先结束内部焦点，以执行原失焦提交；原触发按钮仍可切换关闭。
- 窗口取消走已有回调：不确认删除、不应用优化候选、不启动生成。优化窗口允许外部点击停止本次等待；应用和保存 ACK 未确认期间，以及导入、删除、恢复等现有事务保护继续生效。
- 原生/Radix 选项仍保留自己的外部交互行为，未转换为手工菜单。侧栏等持续工作区域及常驻错误通知不作为弹出面板自动移除。

## 当前实页验收

当前 `http://localhost:3000` 的“粉色皇冠数字蜡烛｜共用尺寸演示”画布：

- 画布外观及生成设置：点击标题等内部区域保持打开，点击画布后关闭；原生过渡结束后不可见。
- Excel 文件下拉：点击画布关闭，未切换工作簿。
- 配置与用户偏好、产品回收站、历史总览、AI 优化窗口：点击面板外遮罩关闭，画布保持已保存。
- 卡片“组装提示词”编辑器：原按钮再次点击能关闭，点击侧栏也能关闭，未更改文本。
- 配置里打开新增渠道的编辑抽屉，展开协议选项并以键盘确认当前 OpenAI 选项后，抽屉与父设置面板均保留；未提交渠道保存。点击顶栏只关闭抽屉，确认父设置仍在；再次点击顶栏关闭父设置。
- 没有调用收费模型、执行删除、恢复产品、下载或提交新渠道。生成中请求取消与保存失败路径由模拟测试覆盖，没有用本次实页检查代替真实渠道验证。
