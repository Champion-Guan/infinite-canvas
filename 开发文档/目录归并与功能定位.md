## 小补丁怎么维护

补丁直接放在根目录`上游适配/`，当前共121份顺序补丁；不再套“基础接入”和“功能接入”子目录。归并前已生效的作者差异按文件保存，使用画布主入口接入等中文名称，在映射中写明目标，不伪称已经按业务全部解耦。后继修改按单一功能保存。例如先用`图片结果保存接入.patch`替换结果回写引用，定向验收后再用`图片结果旧接线清理.patch`移除失效导入；主题入口和过渡也分别用小补丁接线。不再维护一个包含全部差异的总补丁。

正常修改优先只改`扩展功能`对应实现。必须增加作者接入时，先保留，再提取当前接入产物到临时文件，改好后导出该功能补丁。例如：

```sh
npm run dev:snapshot
python3 开发工具/维护接入补丁.py 提取 web/src/pages/canvas/project.tsx /tmp/当前画布接入.tsx
# 编辑临时文件，只加入该功能的导入、回调或组件接线。
python3 开发工具/维护接入补丁.py 导出 web/src/pages/canvas/project.tsx /tmp/当前画布接入.tsx 对应功能接入
npm run dev:check-source
```
