# 基础交互动效规范

用户体验至上是所有设计、代码和验收的最底层标准。本规范适用于现有界面的后续调整以及所有新设计。动效要让用户立即知道操作是否被接收、当前是什么状态、接下来发生什么；不能成为等待、闪烁或误操作的来源。

## 统一规则

### 1. 面板展开与关闭

- 对话框统一复用 `AppleModal`，沿用快捷键面板使用的 Ant Design 原生遮罩淡入及窗口原生进退场。设置面板使用同一默认窗口动效。
- 抽屉复用原生 Drawer；浮动设置面板复用原生 Popover。各类组件使用已有预设、相同主题及动态偏好。
- 打开和关闭都有完整过渡；只在真实退出完成后卸载内容。连续开关可中断旧过渡，旧回调不能关闭新窗口。
- 面板外点击和 Escape 走原有取消逻辑；触发按钮再次点击关闭。触发器必须登记到面板边界，不能捕获阶段先关闭、click 阶段又打开。嵌套选项不误关父层。
- 真实保存或事务未确认时保留必要关闭门禁；关闭不提交、不删除、不擅自应用编辑。
- 子控件测量或布局出现问题时修正子控件，不能通过给单个窗口临时换一种动画来绕过问题，也不在原生窗口内部再叠加缩放。

### 2. 下拉菜单与选项浮层

- 复用 `OutsideDropdown`、`OutsideSelect`、`OutsidePopover` 及现有原生设置浮层，沿用原生方向、定位和进退场。
- 同一类入口的展开、收起、选中、禁用、悬停和键盘反馈一致。点击外部、再次点击触发器或完成选项操作时按既有语义关闭。
- 保留原生 Portal、方向键、Enter、Escape、边缘避让和焦点行为；不另外叠加 CSS/Motion 入场，不设置固定卸载延时。

### 3. 页签内容双向交接

- 新页签立即淡入，旧页签同步淡出；不等待旧页退出后才显示新内容。
- 原生 Tabs 使用 `NativeFadeTabs`；自定义页签及切换内容的分段控件使用 `TabContentTransition`。内容淡变基准为 `TAB_FADE_DURATION`（180ms），原生 Tabs 的主题时长与其一致。
- 自定义交接最多保留当前内容和最近一层退场内容。退场内容立即 inert、aria-hidden，不接收鼠标或键盘；结束后卸载。
- 表单值、勾选和真实业务状态按原生命周期保留，不为动画重建工作区或重复请求。产品切换保留热画布、后台保存和五分钟安全空闲休眠。

### 4. 页签横条与滑动选中背景

- 左侧页签、设置、模型选择、插件和 Agent 的下划线共用 `useUnifiedTabIndicator`，不再各写一套 CSS 缓动或 Motion 参数。
- 横条复用胶囊的同一原生弹簧播放器：距离、宽度和连续改向速度共同决定收敛；远距离更快、阻尼更高，近距离保留自然弹性。
- 只在目标变化时采样弹簧，交给 Web Animations API 播放。中途改向从当前呈现位置、宽度和速度接续，不跳回旧起点，不排队。
- 首次出现、恢复可见和布局调整直接就位；读取布局坐标，避免窗口缩放、按压缩放造成横条漂移。不得以重新挂载导航条校正位置。
- 保留控件既有外形和位置。顶部产品胶囊仍使用胶囊背景，不把它改成下划线。
- 横向浏览使当前选中项离开可视区域时，在对应边缘显示方向和当前项名称，点击可定位回来。提示使用原生淡入淡出，不挤动导航内容；提示本身也属于同一滚动区域，保留滚轮和触控手势。自由浏览不强行回到选中项；定位使用浏览器平滑滚动并返回当前页签焦点，减少动态效果时直接定位，不改变业务选择或触发保存。

### 5. 按钮开关

- 二元启用状态统一使用 Ant Design `Switch`，使用现有中性主题与深浅色 token；轨道、圆形滑块、选中颜色、禁用态、悬停和焦点样式遵循同一组件。
- 只使用已有的标准尺寸和 small 尺寸，按场景密度选择；同一层级一致。禁止再用隐藏 checkbox、手绘轨道和自定义滑块拼出另一套开关。
- 点击立即反馈，滑块沿原生轨迹移动。异步提交明确显示 loading/disabled；失败保留或恢复真实状态，并说明原因。
- 首次异步读取期间使用等尺寸中性占位；拿到真实值后再挂载开关。不先显示假默认值再切换成已保存值，不把面板打开或状态恢复表现成一次用户开关操作。
- 保留键盘 Space、可访问名称和 checked 语义；不改变业务含义，不把按钮动作改成持久开关。

### 6. 按钮按压与选中状态

- 操作按钮优先复用 `AppleActionButton` / `AppleAntButton` 和 `APPLE_CONTROL_SPRING`。按下即时、松开自然回弹；禁用和减少动态效果时不缩放。
- 选择模式复用 `SelectionInline` / `SelectionFooter`。勾选框、文字占位、背景和底栏进退同路；保留行高和滚动位置，退出不抖动。
- 滑杆、拖动、缩放、尺寸调整等直接操纵控件跟随输入，不在手势关键路径上增加延迟或几何弹簧。

### 7. 悬浮说明与通知

- 复用原生 Tooltip，统一同一工具栏的出现时机、间距和最大宽度，并避开关键信息。键盘用户也能查看说明。
- 悬停显现的操作按钮由真实 hover 或键盘 `:focus-visible` 显示；普通鼠标点击留下的焦点不能使按钮在鼠标移开后常驻。触摸设备保留可发现的入口。
- 执行动作后收起说明，弹窗归还焦点不自动重新弹出旧说明；重新悬停或再次 Tab 聚焦时可再次查看。
- 同一阻断原因复用已有提示，不堆叠重复浮层。重复点击受阻动作时可用现有提示的克制强调反馈；不能伪装成已经执行。

### 8. 主题切换

- 所有手动主题入口复用 `AnimatedThemeToggler` 和 `runThemeTransition`，以现有圆形扩散、触发位置起点、400ms 为统一基准。不得为不同入口另设形状、全屏闪白或颜色过渡。
- 连续切换以最后一次选择为准，跳过旧过渡并清理旧截图和样式；不阻塞用户操作。
- 无 View Transition 支持或启用减少动态效果时直接应用主题。启动、加载及恢复画面从第一帧使用已确定主题，不经过白黑白闪回。

### 9. 加载、进度与失败反馈

- 点击立即给出真实的等待、进行、保存、成功或失败状态。骨架与最终内容同主题、同布局，快速完成不闪一下骨架。
- 不编造百分比，不把等待网络、写入存储或切换视区混成同一状态；失败提示包含可理解的原因及可执行的恢复入口。
- 不因动画延迟已就绪内容，不用保存阻塞可安全进行的导航，不通过销毁实例取消用户生成任务。

## 所有类别共同遵守

- 新设计先确定所属类别，并复用已有组件、播放器和主题参数；需要新增类别时同步补充本规范、公共实现与验收依据，不在业务组件中散落新的动效常量。
- 优先浏览器原生 CSS / Web Animations / Ant Design 播放；主要动画化 transform 与 opacity，减少布局、重绘和每帧 JavaScript 工作。
- 快速反向操作、连续点击、减少动态效果、窗口/产品隐藏及卸载都必须有明确行为；及时取消动画、计时、观察器与监听。
- 不靠动画期间禁用整个界面解决竞态；退场层不可交互，新内容和触发入口立即响应。
- 深浅色、焦点、键盘、状态语义、文本可读性和点击区域一并验收。
- 按实际入口完整测试，检查保存、恢复和失败边界。测试或构建通过不能替代实页验证；未启用的功能、未验证场景如实记录。
