# 分类系统提示词

## 最终界面

- 设置的偏好页保留一处“系统提示词”标题，分类控件仍在标题下方，包含生图、文本、视频、音频。
- 各分类仅显示一个编辑框，不再重复显示“文本系统提示词”等可见子标题；通过 aria-label 保留分类名称供键盘与读屏使用。
- 生图编辑框显示既有 AI 写提示词的完整角色背景，可直接修改及恢复默认；不再展示额外的生图通用编辑框。
- 音频分类沿用原 audioInstructions，替换原单独的默认音频指令入口，不复制一份新设置。
- 分段控件复用 Ant Design，内容切换复用 TabContentTransition，编辑区行数与基础高度保持一致。

## 请求与兼容

- AI 写提示词在任务开始时读取自定义角色，保留原有固定双语 JSON 输出约定、商品资料和平台规格。翻译及提示词优化保留各自输出任务，不混入普通文本系统角色。
- 文本和视频按模型能力读取各自指令；视频 OpenAI 与 Gemini 创建请求均带入视频背景。音频指令仍进入 instructions，朗读 input 保持原文。
- 原全局 systemPrompt 的旧图片/文本行为保留，旧视频不新增旧全局背景。类别字段的默认 null 与用户显式清空的空字符串分开处理，重复解析渠道不跨类别污染。
- 新配置沿用原 SQLite 保存队列和脱敏导入导出。可选文本字段仅接受 null 或 string，旧文件缺字段使用兼容默认值，不修改凭据处理。
- 两个新增根模块和修改模块均登记来源指纹，作者设置、配置解析和视频入口通过三个独立补丁接入。
