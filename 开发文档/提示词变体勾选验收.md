# 提示词变体勾选联动

## 实现

- 商品提示词卡每个变体名称旁新增生成勾选框，右上角新增全选及半选状态。
- 勾选状态直接读取并更新关联参数卡的 `productVariants[].enabled`，没有新增第二份卡片局部选择。
- 点击非当前变体文字只切换查看，再次点击当前变体文字勾选或反选；复选框始终直接勾选。方向键只切换查看，保留提示词编辑、双语及图片引用，取消选择也可查看原内容。
- 新变体沿用默认全选，旧数据缺少 enabled 字段时默认选中；已有明确 false 不因打开卡片而重置。
- 生成配置卡、全画布批量及策划完成批量遵守勾选选择；提示词卡底部“生成当前变体”是明确的单独生成命令，不受是否勾选影响。
- 关联参数组全部取消时批量跳过，不退回普通无变体执行，也不阻断其他产品组；整批无任务时提示先勾选。
- 选择通过原节点事务保存，保留其他变体资料、配图及已有任务快照。不撤销已提交的在途请求，不重写旧图片。
- 勾选和切换页签阻止画布拖动事件；页签保留方向键、Home、End 和键盘焦点操作。
- 变体栏复用顶部产品胶囊的鼠标拖动，6px 后识别为拖动并抑制随后点击；点击变体后在栏内居中，支持画布缩放及减少动态效果，首尾按滚动边界停靠。
- 提示词卡底部单变体生成按钮在原任务身份保存、本机接受提交之后取消本次变体的勾选，联动参数卡和批量张数。多张图片回执只取消一次；切换查看其他变体不改变本次取消目标；用户随后重新勾选不会在任务结束时再次被取消。提交前检查、身份记录、提交失败均保留原勾选。

## 勾选响应优化

- 原勾选走通用节点操作，每次创建新的画布选中集合、清除连线选择和菜单；双语文本框还在每次渲染后读写镜像几何，提示词正文和引用也重复编译。
- 纯元数据操作保留画布选中集合、连线选择、菜单及视区身份，继续写入同一节点事务和撤销快照；真正的选择、增删、连线、视区命令继续原逻辑。
- 只改变变体 enabled 时，正文快照复用，用于待确认正文编译、图片引用目录、双语投影及对齐偏移。原始参数卡的 productVariants 仍是唯一勾选来源，正文快照不用于选择或生成决策。
- 变体增删、重排、名称、属性、配图、共用资料、平台语言及其他元数据变更立即使快照失效，不用字符串化整份资料判断相等。
- 文本框镜像只在文本、样式、主题或尺寸改变时重新测量；滚动继续即时同步。保留 ResizeObserver、双语定位和缩略图引用。
- 新增 `开发工具/变体勾选响应.test.mjs`：模拟100次勾选，正文编译1次、双语引用投影2次；模拟100次不改正文的文本框重渲染，计算样式读取次数没有增加；文本、主题及尺寸改变后均重新测量。50次纯元数据事务不调用选择、连线、视区及菜单状态更新。
