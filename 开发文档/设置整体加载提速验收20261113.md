## 本次修改

- 鼠标进入设置按钮或键盘聚焦时预载设置代码，与实际打开复用同一加载请求。

- 未访问的 Fallback 不预先挂载；代理、存储、更新和提示词来源按可见状态读取。提示词来源状态采用现有查询缓存，30 秒内复用，后台不主动重复查询。

## 测量边界

本轮通过浏览器通道记录的一次操作观测：设置首次打开约 708 ms、重开约 298 ms；Fallback 切换约 441 ms、本地存储首次内容显示约 318 ms、软件更新切换约 383 ms。这些时间包含自动化调用和可见性检查开销，并非 API 耗时、连续性能基线或所有机器的速度承诺。全库统计仍需实际读取；优化使其不占用服务主线程，并让已有结果在重新核实时继续显示。

## 后续调整：打开设置时刷新容量

按用户后续要求，将容量统计的触发从“进入本地存储页签”改为“每次打开设置面板”。本地存储内容在设置首次打开时初始化，统计可在其他页签停留期间完成；切页不再次扫描，手动“刷新统计”和清理完成后的更新继续保留。

实页复测同时发现，AppleModal 的退出快照会保留打开时的子内容属性。设置内容现直接订阅弹窗开关，避免隐藏时遗漏关闭状态、重开时不触发刷新；独立设置页面仍沿用自身活动状态，原弹窗退场快照和动画保持。
