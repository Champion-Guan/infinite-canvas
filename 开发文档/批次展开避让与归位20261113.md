# 批次展开避让与归位

用户明确要求：展开批次时让其他卡片临时避让，收起时回原位；屏外时适度平移视区；按钮隔离双击，避免误开图片详情。随后要求避让与归位都有平滑动画。本次未采用提高层级盖住其他卡片的方案。

## 实现

- `批次展开避让.ts`按原批次最多四列、18px间距的实际展开范围计算占位。受影响的普通卡片找最近的无冲突位置，目标位置同时避开其他卡片与展开批次；多个展开批次分别预留，其他组作为整体移动。批次所在组内的子卡参与避让，显示组边界随子卡扩展。
- `批次展开显示.ts`只生成显示坐标，不写原节点、元数据、保存或撤销历史。连线、顶部工具栏、可见区域索引、框选、定位使用显示坐标；原图延迟恢复仍传原节点对象，避免临时偏移混入媒体恢复写回。用户缩放卡片时转换回原坐标。用户拖动以原坐标增量工作，展开偏移在同一展开结构中保持，收起撤掉偏移。
- `批次避让过渡.ts`用240ms cubic ease-out在临时坐标间过渡。中途反向从当前坐标接续，过渡中的坐标同步用于卡片与连线；不通过只动画DOM卡片造成连线停在终点。隐藏产品或减少动态效果即时应用，卸载取消帧调度。位置同步确需逐帧，其他定位和业务提交不进入过渡循环。
- 视区复用已有弹簧平移，只补足新展开区域屏外部分，不改变缩放。超大批次可继续手动平移浏览，保留根卡收起按钮在安全范围内；收起不强行撤销用户已调整的视区。
- 独立补丁`批次展开临时避让接入20261113.patch`负责原画布接线；`批次按钮隔离双击20261113.patch`给图像/文本批次数量按钮增加aria-expanded及双击隔离。卡片正文双击入口排除button和role=button目标，按钮内图标也不触发正文详情。

## 验证

- 28项批次避让、图片批次操作及批量结果排布测试通过。覆盖原坐标不变、收起精确还原、多展开批次、负坐标、15张多行、组整体移动、视区缩放不变、超大批次收起按钮可达、240ms连续坐标、途中反向、减少动态效果及调度清理。
- 从真实卡片源码提取双击处理器执行：按钮及按钮子图标不打开详情，普通图片正文仍打开详情。保留既有设主图、复制、删除、尺寸与异步回调测试。
- 完整TypeScript、React/Hooks检查通过；源码归并一致。临时提取的两份作者文件在补丁导出后清理。没有提交、推送或发布。
