# HEIC 自动兼容验收

## 原因与修复范围

旧上传链依赖浏览器原生解码。Chrome 对 HEIC/HEIF 支持不完整，Safari 能显示也不代表图像模型接受这种输入。此前修复只保证失败不堵住 SQLite 保存，没有实现转换。

本次在公共图片上传入口增加本机转换：macOS 自带 `/usr/bin/sips` 将 HEIC 转为 JPEG（质量 95，不缩小尺寸）。预览、编辑、缩略图和生成参考图继续读取 `storageKey` 的 JPEG；`originalStorageKey` 单独保存原始 HEIC。原图下载按实际 MIME 使用 `.heic` / `.heif`。不会把原文件上传给转换网站。

## 文件与接线

- `扩展功能/媒体交付/HEIC格式识别.mjs`：检查 ftyp 品牌，处理空 MIME，区分 AVIF、坏文件和同名伪装。
- `扩展功能/媒体交付/HEIC上传兼容.mjs`：共享上传前处理，区分原图和交付图；普通图片沿用原对象。
- `扩展功能/媒体交付/HEIC转换客户端.mjs`：有界二进制请求、结果协议检查、取消和错误提示。
- `扩展功能/媒体交付/HEIC本机转换.mjs`：固定系统命令、尺寸检查、队列与临时文件生命周期。
- `扩展功能/媒体交付/HEIC转换HTTP入口.mjs`：复用现有页面授权，限定同源 POST，不接收本机路径或命令。
- `扩展功能/本机存储/本机授权客户端.mjs`、`工作台自动入口.mjs`：复用原会话接入媒体转换端口。
- `扩展功能/本机服务/受限工作台启动器.mjs`：装配、排空转换服务。
- `扩展功能/生成历史/媒体文件扩展.js`：原图下载扩展名。
- `上游适配/HEIC本机转换与原图分离接入.patch`：公共 image-storage 上传前转换、分开持久化。
- `上游适配/HEIC无类型文件选择与拖入接入.patch`：画布文件选择/拖入接受空 MIME 的 HEIC。
- `上游适配/HEIC素材选择与原图信息保留接入.patch`：素材库接受 HEIC 并保留原图信息、显示实际失败原因。
- `上游适配/开发源码映射.json`：登记前后端依赖与上述三个接入补丁。
- `开发工具/HEIC自动转换.test.mjs`、`package.json` 的 `test:heic`：专项检查入口。

## 资源边界

输入、输出分别最多 32MiB，输入最多 8000 万像素。最多四个已授权请求，转换串行运行。探测超时 10 秒，转换超时 30 秒，取消/超时结束自己的子进程。转换前保留 1GiB 磁盘余量及本次输入输出预算；输出增长时检查大小，结束后再校验。临时目录 0700、输入文件 0600，成功、失败和取消均清理；后续启动只回收本功能中所属用户、已退出进程的残留。未启用自动备份，没有增加 npm/WASM 解码依赖。

JPEG 兼容副本可能比 HEIC 大；它是客户上传图片的正式交付数据，原图同时保留。转换暂存完成即清除，不保留多份中间转换结果。

## 自动检查

- 有效 HEIC、HEIF MIME、空 MIME、品牌识别、AVIF 区分、坏文件、大小与像素上限、磁盘不足、串行队列、取消、错误恢复、暂存回收、授权客户端/HTTP：通过。
- HEIC 新专项 11 项、此前上传保存 5 项、本机授权 12 项：28 项通过，含用户提供文件的真实系统转换。
- 受限启动器和本机数据服务的 15 项附加回归：通过。
- `npm run test:disk-guards`：116 项通过。
- 最终完整 TypeScript、Vite 编译：通过。
- `npm run dev:check-source`：515 个装配文件、1530 个引用、397 个独立根来源、187 个顺序补丁，旧前端引用 0。

实际 HEIC 检查可通过 `GUAN_HEIC_TEST_FILE` 指定本机文件；未提供时只有该实文件项跳过，其余测试不依赖客户照片。

## 实页验收

在既有 Chrome / localhost:3001 页面进行，没有新建工作台、测试窗口或重置数据。

1. 上传用户提供的 5,987,666 字节 HEIC：成功创建卡片并保存，详情预览正常。
2. 交付 JPEG 为 10,852,839 字节，尺寸 5712×4284；详情格式为 jpg，存在“下载原生图片”。
3. 刷新原页面、通过侧栏搜索定位该卡片、再次打开详情：图片正常恢复，尺寸与原图下载入口保留。
4. 点击“下载原生图片”：实际文件名后缀 `.heic`，5.7MB，Chrome 显示完成。SHA256 与原文件一致：`0c9325c116263e2163debd92cd29b2664cd13a7d33e578849706f729f00229f8`。验收下载副本随后删除，用户原文件保持。
5. 通过当前画布的“删除选中”移除本次验收卡片，搜索列表不再显示该节点，清空搜索后状态为“已保存”。不清空回收站，不删除客户既有数据。
6. 运行临时目录检查：HEIC 转换暂存残留为 0。旧项目 3000 的 PID 1436 保持；新项目 3001 PID 96840，原工作区 UUID 保持。

中文截图留在本机 `开发文档/验收记录/HEIC自动转换20261027/`，包含首次详情、刷新后详情与移除后保存状态，不随代码发布客户图片。

## 未验证及发布边界

- 本轮未触发收费生图；参考图使用 JPEG 的路径经过代码核对及存储类型验证，模型实际生成未执行。
- Safari、另一台 Mac、其他 HEIF 编码样本未做本轮实页验证。
- 当前转换器依赖 macOS 系统能力；其他系统明确报不支持，不会阻塞保存或伪装成功。
- 已在本机开发 3001 生效，尚未打包或发布下一客户版本，公开 beta.14 不包含本次修复。
