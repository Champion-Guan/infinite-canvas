# 交互与编辑面板修复验收

环境：既有 `http://localhost:3000`，沿用当前工作区及测试产品。前端由现有开发监听器构建，没有运行独立工作台，也没有触发付费生成。

## 修复范围

- Fallback 列表和自定义默认排序复用浏览器原生换位播放器；分段能力切换复用统一横条及双向淡变。
- 下拉菜单包含侧栏及顶部触发器，不再使用排除触发器的画布边界。二级菜单保留完整的 1px 边框和 16px 圆角，选项高亮为 10px 圆角。
- 菜单滚动条闲置时隐藏，实际滚动后显示，停止 700ms 后淡出。Select 虚拟列表滑块宽 4px，不再使用默认 8px。
- 提示词来源内容窗口居中，表格内部滚动，分页固定。更新按钮和关闭按钮中心对齐；成功、失败使用原有消息提示入口。
- 提示词详情以实际按钮作为首帧动画锚点，并登记为内容窗口的子面板，关闭详情不连带关闭列表。
- 模态窗口高于画布编辑器；原生选项容器跟随所属模态窗口层级，避免修复一层后覆盖另一层。
- 编辑面板定位外壳不参与缩放，先按真实画布边界定位，再播放内部入场；尺寸不足时预留编辑所需空间。设置窗口按最新要求锚定按钮，允许覆盖编辑区，保留按钮安全间距。
- 放大编辑进入参考选择时保留恢复快照，退出后恢复放大窗口。普通编辑退出参考也使用已测量的位置，避免从左上角闪入。
- 输入与占位共用内边距及边框。输入法组词期间隐藏占位；空格同样视为输入；删除后遗留的单个空 BR 按真正空内容处理。
- 分类加载保留上次结果，禁止点击过期列表；新结果就绪后双向淡变，固定字号、滚动区域及布局，退场完成移除旧列表。
- 产品切换的画布过渡与侧栏外框分离。侧栏固定控件不参与整页透明度动画，只对内容交接；新产品不重复从零宽度展开侧栏。
- 边缘“当前产品”提示的透明度根据胶囊越界距离连续变化，配合 180ms CSS 过渡；反向滚动不排队，不改变选中产品或触发保存。

## 实页证据

- 两个排序入口可换位；主列表等待 SQLite 确认后更新。验收中将主列表交换两次恢复原顺序，自定义排序仅修改草稿后取消。
- Fallback 音频、生图切换后只保留一个当前内容层，横条目标宽度及位移正确。
- 来源内容窗口为 980px 宽，视口 612px 高时上下边距均约 47px；更新按钮与关闭按钮中心同为约 75px。
- 实际更新 Banana Prompt Quicker 成功，观察到白色提示“已更新 323 条”。
- 详情窗口、来源窗口、设置窗口层级分别为 1800、1700、1600；关闭详情后“立即更新”仍可见。
- 推理二级菜单的实际边框为 `1px solid rgb(201,201,201)`，圆角 16px，外容器圆角 0，不裁掉内部圆弧。
- 侧栏筛选实际选中“图片”；选项实际圆角 10px。虚拟滑块实际宽 4px，闲置透明度为 0，真实滚动事件启用显示状态。
- 连续切换三个提示词分类时，窗口始终为 `left=280, top=80.28125, width=880, height=451.4375`。加载没有清空分类；过渡后只保留一个内容层、20张卡片。
- 放大编辑进入参考选择再退出后，“编辑提示词”窗口仍打开，保留按钮锚点坐标。
- 输入普通文字后占位属性消失；输入单个空格后占位同样消失；全选删除后 DOM 为 `<br>`，占位恢复。
- 设置窗口在按钮上方，测得面板底边约 463px、按钮顶边 470px；编辑器底部全部按钮均位于面板内部。
- 四次产品切换后，侧栏宽度均为 `324.1015625px`；外框、父容器和产品场景容器透明度均为 1。
