# SQLite 单文档限制调整

日期：2026-10-29

旧协议的 `2 MiB` 单文档上限是应用层常量，不是 SQLite 的限制。为避免普通画布文档在较小体积时被拒绝，现将文档 JSON 上限调整为 `32 MiB`，与分片应用存储的逻辑数据预算一致。

HTTP 写入正文额外允许 `1 MiB` 用于文档信封和媒体哈希引用。正文仍有界，过大请求返回 `413`；分片应用存储仍保留逻辑命名空间大小、分片数量和完整代提交保护。

本次只取消旧 `2 MiB` 边界。整份 Zustand 状态仍会在浏览器侧克隆、解析和编码，32 MiB 文档也可能产生较高内存和主线程开销；按产品/节点增量保存仍是后续性能改进方向。
