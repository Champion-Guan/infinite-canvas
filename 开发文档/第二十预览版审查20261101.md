# Web 2.0.0-beta.20 发布前审查

本次修复页面授权超时、整批生图及历史重试、图片详情尺寸和保存恢复，沿用原工作区、原可信签名与 Web 预览渠道。

## 已验证

- 85 个现行测试文件：907 项检查，906 通过、0 失败、1 跳过。覆盖保存/重试、任务去重、代理、更新、磁盘保护和媒体交付；不代表收费生成验收。
- 34 图真实本机 HTTP 并发提交，超过 120 次查询，跨一天后恢复原会话；258 笔累计任务保留身份，每笔只发起一次合成上游请求。
- 默认页面授权跨 3 天休眠仍可恢复 SQLite 保存，关闭页面立即撤销；短期数据令牌仍按原页面透明续接。
- 旧多块画布冷读后转为单文档保存，原记录保留；错误 ACK 不确认成功，同一操作重试后恢复。
- 完整 TypeScript 检查通过；197 个 React 模块与 750 个 JavaScript 模块检查无问题。
- 当前 localhost:3000 刷新后，原未命名产品3恢复 87 个节点并显示已保存，图片详情保留交付图与原图尺寸。

## 主要变更

- 页面租约默认不计时结束；服务退出、页面关闭及明确撤销仍结束授权。移除已授权业务的固定请求并发拒绝和生成账本累计 256 条限制。
- SQLite 写入与备份恢复互斥排队，默认排队不因计时丢弃；收费生成继续并行。
- 修复保存恢复期间的新编辑提前失败、旧分片读取、媒体 MIME 丢失、空 MIME 上传、BLOB 返回类型、手动备份 BLOB 核验和存储回执校验。
- 修复资产恢复时不同媒体类型的条件收窄、渠道元数据类型和恢复状态判断的类型错误。
- 图片详情尺寸主值使用最终保存文件宽高；请求参数不作为主值。原图尺寸不同则继续在右侧显示。
- 沿用现有 Motion/CSS/Ant Design 方案，统一短时长与弹簧过渡，保留系统减少动态效果偏好。
- 渠道地址变化时禁止将不可逆 provider 引用作为新 API Key 写入；需输入该地址的完整密钥，原绑定保留。
