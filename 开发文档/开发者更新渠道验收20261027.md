# 开发者更新渠道验收

日期：2026-10-27。开发来源为根目录 `扩展功能/`；服务为现有 localhost:3001，保留原工作区。旧项目 localhost:3000 的进程与服务保持运行。本轮未推送或发布 GitHub，未安装真实更新包。

## 行为与接线

- 设置 → 软件更新的原开关行新增“开发者模式”，默认关闭；开启接收 Web Beta 和 Stable，关闭只接收 Web Stable。顶部版本弹窗共用同一后端结果。
- 固定仓库 Champion-Guan/infinite-canvas，只接收 `web-v*` 的匹配发布包；不混入旧应用 `v1.2.8`。草稿、Alpha、RC 和 GitHub 预发布标志与版本号不一致的记录均不接收。
- 切换后清除旧候选和检查缓存并自动重新检查；关闭时取消不适用的 Beta 下载和排队安装，暂存、确认、安装恢复及实际切换前均重新核对渠道。安装进行中不能切换。
- 不降级或停止当前已安装的 Beta；Stable 包可继续通过两个模式接收，仍需版本更高、原可信签名和完整库存验证。
- 偏好保存在软件更新私人目录的 `开发者更新偏好.json`，不向旧 `preferences.json` 增加未知字段，保持旧版本回退读取兼容。
- 新模块为 `扩展功能/软件更新/更新发布渠道.mjs`；前端复用现有 Switch 和布局。其余接线涉及软件更新服务、GitHub 读取、客户端文案、在线安装操作、Web 协议、客户命令及独立安装管理器。未新增作者接入补丁。
