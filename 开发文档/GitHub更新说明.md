# AI-Workbench v2.0.0-beta.31

本次更新完善渠道竖图尺寸适配和任务保存续接，同时改善画布缩放、图片预览、大产品导入及提示词菜单操作。

## 新增

- **渠道竖图请求适配**：接口域名为 `api.kunrouai.com` 的 GPT Image 型号在3:4请求时，`-4k`使用2448×3264，`-1k`使用1086×1448，渠道可自由命名。1800×2400等自定义尺寸按目标等比交付；旧2480×3312预设按适配尺寸交付。800×500等其他比例沿用各自尺寸。

## 优化

- **画布缩放与图片显示**：分级加载预览并复用已加载图片和连线，减少屏外内容重复绘制，改善缩放、平移和图片交接。
- **产品导入**：大产品包异步解压并显示进度，减少导入过程对界面操作的阻塞。
- **提示词与配置菜单**：提示词先预览详情再应用，完善选项下拉、Esc关闭、模型配置提示和设置浮层定位。

## 修复

- **任务保存续接**：拖动、缩放或定位期间等待可保存画布，操作结束后自动继续，避免短暂忙碌中断任务保存。

## 使用说明

- **安装与更新**：支持Apple Silicon macOS；已有安装版开启开发者模式后，从“设置 → 软件更新”中检查更新。个人配置、产品和历史素材保留。
- **已有任务与费用**：适配用于新提交请求，不自动重新生成历史失败图片；模型调用仍可能产生费用。需要大图细节时优先使用4k型号，1k结果放大不会增加原始细节。
