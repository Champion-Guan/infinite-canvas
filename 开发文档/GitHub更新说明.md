# AI-Workbench v2.0.0-beta.38

本次更新改善含大量原图的画布导出，并更新 AI 写提示词的补齐流程、文本卡片保存和画布弹窗定位。

## 新增

- **变体提示词进度**：AI 写提示词自动补齐缺失变体时，显示完成数量和总数。

## 优化

- **大画布导出**：从画布菜单选择「导出当前画布」，工作台会逐个读取媒体、分块打包，让页面在导出期间保持响应。
- **AI 写提示词**：如果策划结果缺少部分变体，工作台会自动分批补齐。连续补齐无进展时，已返回的方案会保留，可通过「继续修正」恢复。

## 修复

- **文本卡片保存**：输入后立即点击画布空白处，会先提交本次编辑再退出。
- **卡片编辑面板**：卡片旁有足够空间时就地打开编辑面板，减少自动平移和回弹。
- **批量操作与图片详情**：链条按钮的批量菜单在底部工具栏上方展开，图片详情在产品栏下方的工作区内居中，标题和操作按钮完整显示。
- **桌面启动**：再次启动工作台时，会刷新仍停留在连接失败页的已有 Chrome 标签。

## 使用说明

- **版本与更新**：本版适用于 Apple Silicon macOS。已安装工作台的用户可开启开发者模式，在「设置 → 软件更新」检查预览版。
