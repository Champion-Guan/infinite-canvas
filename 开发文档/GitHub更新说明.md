# AI-Workbench v2.0.0-beta.29

本次重点提升整套商品图的趣味设计，增加策划实时预览、图片引用预览和桌面入口修复工具。同时完善策划失败后的继续修正与保存恢复，让变体生成数量、任务通知和本地存储整理更清楚、更方便操作。

## 新增

- **桌面入口修复**：项目和客户安装包新增“修复桌面入口.command”。桌面入口丢失、图标异常或启动脚本损坏时，双击即可创建或修复。
  - **客户安装版**：先核验当前安装版本的可信签名，再修复桌面入口；不切换软件版本，不启动生成任务，也不修改产品数据。
  - **同名文件保护**：已有同名入口无法确认属于本工作台时，停止操作并保留原文件。
- **策划实时预览**：在产品参数卡点击“AI写提示词”，可查看正在生成的整套方案和实际进度。生成结束后继续显示校验、修正及保存状态，确认保存后才提示成功。
- **图片编号与引用预览**：产品主图、资产、聊天和生图页的上传图片显示顺序编号。提示词、商品依据及优化面板中的图片引用显示编号、名称和缩略图，悬停可预览，点击可打开原图。
- **本地存储整理**：在“设置 → 本地存储”中，可扫描到期内容、预览存量整理范围，再确认清理；数据库内部空闲空间可单独确认“释放到磁盘”。
  - **自动清理**：默认开启，默认保留90天，可按需要调整或关闭。
  - **保留范围**：仍在使用的文件和待恢复任务受到保护，整理前可查看具体范围。

## 优化

- **趣味设计策划**：生图系统提示词加强标题造型、信息包装、手绘点缀和场景层次，并根据不同商品品类选择表现方式。整套图片保持统一风格，同时变化构图和设计组合，保留用户设定的每张图任务。
  - **设计进入实际生图**：图标、手绘和排版内容会进入中英文生图正文，避免只写在策划说明中。
- **变体生成数量与输入明细**：生成设置区分“每个变体生成张数”和“实际总张数”，生成按钮同步显示合计。输入统计按各变体实际使用的提示词和参考图显示，悬停或键盘聚焦可查看明细。
- **全局平台规则**：在参数卡的“平台规则 · 全局”入口编辑并保存后，所有选择同一平台的产品和参数卡共用这份规则；不同平台分别保存。
- **产品切换与任务状态**：顶部产品胶囊支持鼠标横向拖动，切换产品时将选中项滚至区域中心。AI策划的校验、修正和保存阶段分别展示，确认保存后才显示成功。
- **图片存储占用**：生成响应与画布图片共用存储，减少重复占用；本地存储分类增加用途和保留状态说明。

## 修复

- **策划编号与待确认条件**：修复图片编号无效、重复，或待确认条件提示词不完整时无法继续的问题。可安全整理的编号自动修正；仍有歧义或条件不完整时，保留候选方案和原卡片，可点击“继续修正”处理已有方案。
- **原任务恢复与保存确认**：根据实际进度显示“查询原任务”“继续保存”“继续修正”或“重新策划”。卡片已经生成但确认未完成时，继续核验原任务和保存结果，避免因其他自动保存更新而误报失败或重复策划。
- **完成通知**：修复复制图片触发旧完成通知、胶囊已读状态回退等问题，按真实任务分别记录通知。
- **画布操作**：修复单张结果定位、参数卡回收保存层级和小地图缩放保持问题；鼠标点击画布后正确接回键盘焦点。

## 使用说明

- **安装与更新**：本版为Apple Silicon macOS预览版。已有安装版可开启开发者模式，在“设置 → 软件更新”中检查更新。
- **已有提示词与图片**：更新不会自动改写已保存的提示词或重新生成图片。新版系统提示词在之后的策划中生效，确认提示词后再手动生成。
- **继续修正与重新策划**：“继续修正”会调用文字模型修正已有候选，可能产生文字模型费用；“查询原任务”和“继续保存”不重新提交整套策划。需要重新制作整套方案时，再选择“重新策划”。
