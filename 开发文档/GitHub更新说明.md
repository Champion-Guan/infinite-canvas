# AI-Workbench v2.0.0-beta.37

本次更新集中改善画布选择与卡片编辑的即时反馈，并优化提示词库和导入过程。

## 新增

- **导入格式反馈**：拖入不支持的文件时显示具体文件名和画布支持的媒体类型，避免误以为文件已导入。

## 优化

- **变体选择反馈**：勾选变体后立即更新复选框和全选状态；连续点击时合并保存，减少等待。
- **提示词库加载**：打开提示词库时优先显示当前可见的提示词，继续滚动再加载其余内容。
- **卡片编辑时机**：卡片先完成画布定位，再显示编辑面板；保持当前缩放比例，避免浮层挡住目标卡片。
- **提示词编辑布局**：固定卡片标题显示，并调整半选状态的位置，让标题、复选框和提示词内容保持稳定。

## 修复

- **快速选择状态**：修复快速切换变体时全选与半选状态跟随不及时的问题。
- **编辑浮层衔接**：修复卡片移动、选择和提示词编辑期间的显示状态冲突。

## 使用说明

- **版本与更新**：本版为 Apple Silicon macOS Web Beta 预览版。已有安装版可在开启开发者模式后，从“设置 → 软件更新”检查更新。
- **已有内容与费用**：本次更新不会自动重写已有提示词或生成图片；生成操作仍可能产生模型费用。
