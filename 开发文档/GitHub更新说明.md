# AI-Workbench v2.0.0-beta.34

本次更新集中改善多节点画布的操作流畅性和浮层定位，同时收敛已下线 Excel 入口，补齐本地服务恢复、存储回收和产品任务状态边界。

## 新增

- **画布性能预算**：多节点画布会按节点复杂度、缩放比例和设备帧预算选择拖动期间的渲染策略，复杂画布优先保证拖动跟手，少节点画布保持完整实时内容。
- **浮层避让测试**：节点工具栏以卡片上方为首选位置，按顶部栏、底部工具栏和视口边界计算垂直避让，避免工具栏进入卡片内容或横向跳动。
- **开发服务恢复工具**：新增启动、重启、状态检查和备用工作台入口，服务异常退出后可以快速恢复本地工作台。

## 优化

- **多节点拖动与缩放**：合并拖动期间的位置更新和可见范围计算，减少布局参与及 React 高频提交，低倍率大画布操作更流畅。
- **图片与连线渲染**：按视口裁剪图片和关系连线，缩放结束后再恢复完整内容，减少多画布节点下的布局压力。
- **产品与 Excel 边界**：关闭已下线 Excel 功能入口，同时保留已有工作表、产品、素材和回收站数据的恢复能力。
- **本地存储管理**：兼容旧数据的容量统计、恢复和回收站清理，错误提示会保留具体失败原因。

## 修复

- **工具栏定位**：修复节点工具栏在卡片上方有空间时仍进入卡片的问题；水平位置保持稳定，只在垂直方向避让遮挡区域。
- **画布交互**：修复顶部栏、版本入口、浮层层级、节点定位、选择参考及空白区域点击冲突。
- **任务与来源回写**：修复产品参数卡、商品策划、图片审核、翻译配置和生成历史跨产品串用状态的问题。
- **图片交付**：规格或比例不符时保留上游真实图片和实际尺寸，不拉伸、不裁切、不重复生成。
- **节点关系**：修复复制粘贴节点时参考连线丢失，以及聚焦节点时面板和工具栏被视口裁切的问题。

## 使用说明

- **Excel 功能**：Excel 新入口已关闭；已有工作表、模板、产品、画布卡片、素材和历史数据不会被删除。
- **Beta 预览版**：本版为 Apple Silicon macOS Web Beta 预览版。已有安装版可在开启开发者模式后，从“设置 → 软件更新”检查更新。
- **已有内容与费用**：更新不会自动重写提示词或生成图片；新的画布性能和策划规则会在后续操作中生效，调用模型仍可能产生费用。
