# AI-Workbench v2.0.0-beta.32

本次更新为指定渠道的大图请求优先使用同名4k型号，保留用户目标交付尺寸，并完善实际型号记录。

## 新增

- **大图同名型号优选**：仅接口域名为 `api.kunrouai.com` 的渠道，尺寸属于2k或4k时，若同一渠道已配置完全同名的GPT Image `-4k`型号，则从`-1k`自动切换。例如`gpt-image-2.6-sunburst-1k`只切换到`gpt-image-2.6-sunburst-4k`，不跨版本或系列替换。3:4大图优先请求2448×3264，再按1800×2400等目标尺寸等比交付。

## 优化

- **实际型号记录**：任务与结果记录实际使用的型号，保留用户原配置及目标交付尺寸。

## 修复

- **重复候选尝试**：Fallback中的1k与4k升级后相同时只准备一次，不重复尝试同一型号。

## 使用说明

- **自动升级范围**：1k尺寸、800×500、auto及纯比例请求不升级；其他渠道不受影响。缺少同名4k时保留原型号，不跨渠道查找替代。
- **历史任务与费用**：已有未决任务继续使用原身份查询，不因新规则重新生成。自动使用4k可能增加渠道费用。
