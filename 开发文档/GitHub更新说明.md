# AI-Workbench v2.0.0-beta.30

本次更新汇总beta.29之后尚未发布的工作台改动，增加整套策划折叠和商品自由输入，完善商品策划、图片质量与错误反馈，并集中改善启动、保存、产品切换及菜单面板交互。

## 新增

- **整套策划折叠**：参数卡中的整套策划支持展开和收起，方便集中查看方案或继续编辑。
- **商品自由输入**：在参数卡填写商品资料与制作要求即可参与策划，详细资料按需展开。所有图片统一追加的要求修改后直接用于后续生图，无需仅为修改追加要求重新策划。

## 优化

- **商品策划与进度**：完善图片依据、待确认条件、文本模型推理强度和大图请求处理，按实际校验、生成配置和保存结果展示任务与胶囊状态。
- **图像质量选项**：统一显示自动、Max、极高、高、中、低六档，按模型能力启用可用选项；已有手动设置继续保留。
- **启动、保存与切换**：优化品牌启动画面与画布交接，减少大图重复编码和保存开销，改善设置加载、产品切换及侧栏稳定性。
- **菜单、排序与浮层**：统一连续圆角菜单、排序换位和分段切换过渡，完善点击外部关闭、嵌套窗口层级、首次出现的按钮锚点及设置面板避让。
- **图片预览与排布**：引用预览紧邻入口并完整显示；批次展开时临时避让，收起后可归位，策划结果与配置保持合理对齐。

## 修复

- **任务恢复与错误详情**：缺失策划任务正确收口，不串用其他产品任务状态；生成失败保留完整错误，图片重试按渠道规则处理。
- **图片交付与下载**：加强实际图片尺寸校验，修复多选下载和参数卡复制时的策划身份处理。
- **保存与编辑面板**：修复内嵌图片导致保存卡顿、输入占位残留、参考选择后编辑窗口恢复、侧栏抖动和首次面板位置异常。
- **软件更新与历史**：软件更新和版本历史读取对应说明，保持原时间线和彩色分类标签；完善更新结果浮动提示及标题按钮对齐。

## 使用说明

- **功能入口调整**：Excel相关入口已关闭，产品统一显示；提示词库及来源管理保留。已有工作表、模板、画布卡片、素材和历史数据保留。
- **安装与更新**：本版为Apple Silicon macOS Beta预览版。已有安装版开启开发者模式后，在“设置 → 软件更新”中检查更新。
- **已有内容与费用**：更新不自动重写提示词或生成图片。新策划规则在后续策划时生效；调用文字或图像模型仍可能产生费用。
