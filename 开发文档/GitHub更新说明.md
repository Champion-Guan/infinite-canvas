# AI-Workbench v2.0.0-beta.33

本次更新重点改善编辑流畅性、保存稳定性和上游图片容错，保留实际返回结果并避免重复生成。

## 新增

- **上游图片容错**：可解码但尺寸或比例不符合的上游图片仍正常入画布，保留原图及实际宽高，不拉伸、不裁切、不重复生成。

## 优化

- **编辑框输入体验**：输入和长按删除期间使用本地草稿，避免每个字符触发画布重渲染；停止编辑后一次性回写。
- **保存调度**：输入或删除后持续 1 秒无变化才保存，连续操作只保留最后内容；显式切换、关闭和任务检查点仍立即保存。

## 修复

- **WAL写入阻塞**：容量统计先释放只读事务再执行慢速分类，避免长读任务阻塞画布保存。

## 使用说明

- **尺寸不符结果**：图片卡片会显示请求尺寸、上游实际尺寸和交付尺寸；规格不符不再阻止图片保存。
- **历史任务与费用**：已有未决任务继续使用原身份查询，不因新规则重新生成；不会因保存失败重复调用上游。
