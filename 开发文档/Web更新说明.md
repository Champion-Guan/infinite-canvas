## AI-Workbench v2.0.0-beta.30 - 2026-11-14

+ [新增] 整套策划折叠：参数卡中的整套策划支持展开和收起，方便集中查看方案或继续编辑。
+ [新增] 商品自由输入：在参数卡填写商品资料与制作要求即可参与策划，详细资料可按需展开；统一追加要求修改后直接用于后续生图。
+ [优化] 商品策划：完善图片依据、待确认条件、文本推理强度和大图请求处理；策划进度、生成配置及胶囊状态按实际结果更新。
+ [优化] 图像质量：统一显示自动、Max、极高、高、中、低六档，根据模型能力启用可用选项，保留已有手动设置。
+ [优化] 启动与保存：优化品牌启动画面和画布连续交接，减少大图重复编码及保存开销，改善设置加载和产品切换响应。
+ [优化] 菜单与面板：统一圆角菜单、排序换位及分段切换过渡，完善外部关闭、嵌套窗口层级、按钮锚点和浮层避让。
+ [优化] 图片预览与画布排布：图片引用预览紧邻入口并完整显示，批次展开临时避让后可归位，策划结果与配置保持合理对齐。
+ [修复] 任务与错误反馈：缺失策划任务正确收口，不串用其他产品状态；生成失败保留完整错误，按渠道规则处理图片重试。
+ [修复] 图片交付与下载：加强实际图片尺寸校验，修复多选下载、参数卡复制身份及编辑器参考选择恢复问题。
+ [修复] 保存与编辑：修复内嵌图片导致保存卡顿、输入占位残留、侧栏切换抖动和首次打开面板位置异常。
+ [修复] 更新说明与提示：软件更新和版本历史使用对应说明，保持原时间线样式，完善更新结果浮动提示及标题按钮对齐。
+ [调整] 功能入口：关闭Excel相关入口，产品统一显示；提示词库与来源管理保留，已有工作表、模板、卡片和素材保留。
+ [文档] 安装与使用：本版支持Apple Silicon macOS；已有安装版开启开发者模式后，在设置的软件更新中检查更新。
+ [文档] 已有内容：更新保留个人数据，不自动重写提示词或生成图片；新策划规则在后续策划时生效，调用文字或图像模型仍可能产生费用。
