## 2.0.0-beta.28 - 2026-11-10

+ [新增] 图片工具栏增加“一键超人”，可快速换语言、换颜色或为产品主体增加尺寸标注，填写要求后直接生成新图。
+ [新增] “一键超人”加入自定义工具栏，可选择显示、隐藏及显示按钮文字，保存后重新打开仍保留设置。
+ [新增] 参数卡的产品主图、变体缩略图和待确认参考图支持点击放大，读取原图并支持缩放、拖动及关闭。
+ [新增] 商品策划中的待确认事项支持填写数值、选择有无或未知、上传参考图及补充依据，并显示关联提示词范围。
+ [优化] 待确认资料仅更新关联的一张或几张提示词，专属依据和照片不再加入整套提示词或全局参考图。
+ [优化] 相同用途的多个变体共用提示词和配置卡，可切换查看和编辑各自文案；生成结果按变体分列、同用途对齐。
+ [优化] 套图按主图、轮播图和富内容的策划顺序排列，不再受生成完成时间或节点拖动顺序影响。
+ [调整] Wildberries结果卡使用“主图”“轮播图 · 用途”“富内容 · 用途”中文名称，便于查找图片。
+ [修复] “一键超人”继承原图实际像素宽高，避免使用默认方图尺寸；上游返回不符比例时明确报错，不拉伸或裁切主体。
+ [修复] 图片工具栏默认显示在卡片上方，仅上方被顶部区域遮挡时移入图片；修复输入焦点引发的画布隐藏滚动和位置错位。
+ [修复] 快捷编辑菜单与按钮位置脱离、悬浮后变宽、编辑框跳动和背景包裹不完整的问题，独立编辑框与对应菜单项顶边对齐并保持间距。
+ [修复] 自定义工具栏中勾选框、图标和文字的垂直对齐。
+ [修复] 跨电脑导入画布时的临时图片地址和嵌套引用，导入后可保存并恢复；缺少原文件时明确提示。
+ [修复] 生图参考图超过14张时提前提示，避免创建多余结果卡；上游请求失败时显示已脱敏的具体原因。
+ [修复] 鼠标操作卡片按钮后按空格平移画布可能误触发策划或生成的问题。
+ [修复] 产品胶囊在动画结束、取消、异常或减少动态效果时缺少实体选中背景的问题。
+ [修复] 版本历史统一展示客户发布记录，Beta条目跟随开发者模式显示。
+ [修复] 更新偏好缺少自动安装字段时按默认值读取，保留用户已明确关闭的选择。
