## 2.0.0-beta.22 - 2026-11-02

+ [新增] 支持空闲时自动安装更新，所有工作台页面停止交互至少60秒且没有编辑或生成任务后自动准备升级；默认关闭，可在软件更新设置中开启。
+ [优化] 手动安装更新只需点击一次，自动等待任务结束、复核安装包并保存全部已打开画布，收到保存回执后继续安装。
+ [修复] 升级完成后持续核对新版本就绪状态，避免进度页停留在启动阶段，确认成功后自动返回工作台。
+ [修复] 安装准备期间取消操作立即生效，旧保存回执不会继续触发安装；页面退出回执丢失时可重试继续安装。
+ [调整] 只有实际开始下载或安装后才显示更新进度面板，没有新版本或尚未下载时隐藏空进度框。
+ [优化] 切换产品后卸下隐藏画布和侧栏图片，减少后台展示资源占用，保存与生成任务继续由原页面处理。
+ [优化] 侧栏、生成历史和图片总览按接近可见区域加载缩略图，减少不可见图片的重复读取和解码。
+ [优化] 缩略图缓存增加128条和8MiB双重限制，同一图片的并发读取合并，删除后不再被迟到响应重新加入缓存。
+ [修复] 缩略图绘制或编码失败时也会释放位图和临时画布，避免异常路径持续占用图片内存。
+ [调整] 更新日志沿用逐条彩色分类标签，分别展示新增、优化、调整和修复内容。
