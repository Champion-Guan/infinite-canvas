# 生图工作台 Web 2.0.0-beta.15

本次更新集中改善 Excel 工作簿、画布资产、卡片整理、生成历史与更新操作体验。

- 修复上传 Excel 后没有进入「提示词来源」的问题。已上传的工作簿自动补显，无需重传；每本显示完整提示词、真实条数和文件名，回收/恢复自动同步，画布内仍按当前产品隔离。
- Excel 菜单新增工作簿回收站，保留关联产品、画布和产物；本地存储增加两类回收站的容量统计及清理入口，保护仍被活跃内容引用的素材。
- 从上传、粘贴、媒体替换等入口添加的图片、视频和音频统一归入当前画布资产；支持从资产拖入画布，外部文件在鼠标松手位置创建卡片。
- 「整理卡片」支持按主图、详情页等自然编号整理同配置的输出图片；生成历史总览移除单图任务重复勾选框和标题。
- 优化 HEIC 图片兼容与失败任务重试；保留原图，按实际请求尺寸交付生成图片，并修复并发任务的卡片状态。
- 软件更新和版本弹窗中的更新按钮保持同行排列；支持开发者模式选择 Beta，更新记录只显示最近5次。
- 新增安装及更新后的桌面入口检查。服务未启动时，点击桌面入口会先启动当前版本，再打开实际网页地址。
- 包含纯净地址栏、Excel 菜单层级、页签横线、图片质量模型识别和存储说明等已验收修复；移除内置 Banana 来源和旧版整批迁移入口。

已有 Web 安装版：打开「设置 → 软件更新」，开启「开发者模式」以接收 Beta，检查、下载并安装。请等待画布已保存及生成任务结束，按当前版本提示操作。产品、工作簿、素材与个人配置保留。

首次安装：下载 `Web-v2.0.0-beta.15-macos-arm64.zip`，解压后双击「安装工作台.command」，然后使用桌面入口或「启动工作台.command」。默认3000端口，占用时自动顺延；Source code 不是安装包。

适用于 Apple Silicon Mac，沿用原可信签名。内置 Mihomo Smart、最大 LightGBM 模型及其更新机制；日志轮换、下载回收和临时依赖清理继续保留。Stable v1.2.8保持原有发布状态。本次本机检查不代表另一台实体Mac的安装结果，未执行收费生成。
