## 2.0.0-beta.29 - 2026-11-12

+ [优化] 生图系统提示词强化标题造型、信息包装、手绘点缀和场景层次，默认生成更丰富的趣味设计，并按商品品类调整表现方式。
+ [优化] 整套图片保持用户指定的独立任务，在统一风格下变化构图和设计组合，减少重复模板。
+ [修复] 策划说明中的图标、手绘和排版设计未进入实际生图正文的问题，中英文设计内容随提示词一起保存和执行。
+ [新增] AI策划支持实时预览整套方案，展示真实生成与保存阶段。
+ [修复] 策划返回图片编号无效或重复时中断的问题，可安全整理的编号自动修正；存在歧义时保留候选和原卡片，支持继续修正。
+ [修复] 待确认字段或条件提示词不完整时丢失修正入口的问题，保留返回方案并仅修正已有候选。
+ [优化] 策划恢复入口区分“查询原任务”“继续保存”“继续修正”和“重新策划”，恢复已有结果时避免重复提交整套策划。
+ [修复] 卡片已生成后因其他自动保存更新而确认失败的问题，继续核验原任务和保存结果。
+ [新增] 产品主图、资产和聊天等上传图片按顺序显示编号，便于与提示词中的图片引用对应。
+ [新增] 提示词、依据说明及优化面板中的图片引用显示编号、名称和缩略图，支持预览与打开原图。
+ [调整] 平台规则改为按平台全局共享，同平台的产品和参数卡统一使用已保存的规则。
+ [优化] 变体生成设置同时显示每个变体的张数和实际总张数，历史各变体数量不同时显示真实合计。
+ [修复] 生成输入统计混合多个变体参考图的问题，按实际请求显示各变体输入数量及明细。
+ [优化] 顶部产品胶囊支持鼠标横向拖动，切换产品时将当前项滚至可用区域中心。
+ [修复] 胶囊完成通知重复出现、复制图片触发旧通知及已读状态回退的问题，按各任务分别记录状态。
+ [优化] AI策划的胶囊状态覆盖校验、修正和保存过程，完成并确认保存后才显示成功。
+ [新增] 本地存储增加自动清理和保留天数设置，默认保留90天，保护仍在使用的文件及待恢复任务。
+ [新增] 本地存储支持扫描到期内容和预览存量整理范围，确认后清理闲置内容，并可单独释放数据库内部空闲空间到磁盘。
+ [优化] 生成图片响应与画布图片共用存储，减少重复占用；存储分类增加用途和保留状态说明。
+ [修复] 单张结果定位、参数卡回收保存层级和小地图缩放保持等画布问题。
+ [修复] 鼠标点击画布后键盘焦点未接回的问题，改善快捷键连续操作。
