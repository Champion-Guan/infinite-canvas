# 生图工作台 Web 2.0.0-beta.21

本次修复旧版在线升级兼容、桌面入口、遗留安装包回收与画布视区保存。

- 修复 beta19 拒绝新版安装包：恢复旧核验器要求的兼容启动入口，并在构建、签名和发布时检查包结构，避免再次发布无法升级的包。
- 修复桌面入口点击无反应：启动脚本改为兼容系统 shell 的变量名，始终读取当前安装版本。补齐工作台图标、图标声明和本应用的 LaunchServices 刷新；启动及升级后自动检查和修复。
- 升级健康检查和提交成功后回收旧的托管安装包；下次启动清理中断下载、缺少或损坏清单的半成品。只保留事务需要的当前、上一和待安装版本，不清理客户产品、素材与配置。
- 修复平移后尚未达到防抖时限就关闭页面可能丢失视区的问题：隐藏页和退出前提交最新视区，保存回执完成前保留退出保护。
- Excel 导入弹窗和工作簿菜单改为可打断的对称过渡；产品胶囊与生成历史按钮增加轻量弹簧反馈，遵循系统减少动态效果设置。
- 逐项复核两份升级和 M1 报告，验证保存失败恢复、串行 SQLite 写入、并发生图请求、磁盘保护和数据库迁移。自动备份继续关闭，账本不再作为功能或升级前提。

已有 Web 安装版：打开「设置 → 软件更新」，在开发者模式中接收 Beta，检查、下载并安装。请等待画布保存和正在执行的生成任务结束。产品、工作簿、素材与个人配置保留。

首次安装：下载 `Web-v2.0.0-beta.21-macos-arm64.zip`，解压后双击「安装工作台.command」，然后使用桌面入口或「启动工作台.command」。默认 3000 端口，占用时自动顺延；Source code 不是安装包。

适用于 Apple Silicon Mac，沿用原可信签名。当前本机验证不代表 Mac B/macOS 15 的实体机验收，未执行收费生成。Stable v1.2.8 保持原有发布状态。

## beta20 已有功能

本次更新集中改善 Excel 工作簿、画布资产、卡片整理、生成历史与更新操作体验。

- 取消工作台页面授权的8小时超时；长时间使用或休眠后自动恢复原数据连接。关闭页面或退出服务仍会结束对应授权。
- 生图及生成历史重试立即并行执行，移除本机提交频率、并发和累计256条任务限制；同一任务ID不会重复发起生成。修复批量结果保存、重试卡片尺寸和单卡运行状态。
- 图片详情左侧显示最终交付文件的真实尺寸，右侧保留上游原图尺寸；移除重复的尺寸处理说明。生成历史查看按钮精简为“查看”。
- 新建产品及导入Excel的新画布自动创建产品参数卡；上架平台和语言放在首位，产品主图放在第二位。
- 修复旧分片画布升级读取、媒体格式恢复和保存回执校验；历史待恢复任务不再阻碍升级。统一轻量弹簧过渡、按钮反馈及设置控件对齐，遵循系统减少动态效果偏好。
- 修复上传 Excel 后没有进入「提示词来源」的问题。已上传的工作簿自动补显，无需重传；每本显示完整提示词、真实条数和文件名，回收/恢复自动同步，画布内仍按当前产品隔离。
- Excel 菜单新增工作簿回收站，保留关联产品、画布和产物；本地存储增加两类回收站的容量统计及清理入口，保护仍被活跃内容引用的素材。
- 从上传、粘贴、媒体替换等入口添加的图片、视频和音频统一归入当前画布资产；支持从资产拖入画布，外部文件在鼠标松手位置创建卡片。
- 「整理卡片」支持按主图、详情页等自然编号整理同配置的输出图片；生成历史总览移除单图任务重复勾选框和标题。
- 优化 HEIC 图片兼容与失败任务重试；保留原图，按实际请求尺寸交付生成图片，并修复并发任务的卡片状态。
- 软件更新和版本弹窗中的更新按钮保持同行排列；支持开发者模式选择 Beta，更新记录只显示最近5次。
- 新增安装及更新后的桌面入口检查。服务未启动时，点击桌面入口会先启动当前版本，再打开实际网页地址。
- 包含纯净地址栏、Excel 菜单层级、页签横线、图片质量模型识别和存储说明等已验收修复；移除内置 Banana 来源和旧版整批迁移入口。

内置 Mihomo Smart、最大 LightGBM 模型及其更新机制；日志轮换、下载回收和临时依赖清理继续保留。
