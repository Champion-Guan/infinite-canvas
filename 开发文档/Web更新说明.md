## AI-Workbench v2.0.0-beta.35 - 2026-11-19

+ [新增] 画布性能预算：根据节点复杂度、缩放比例和设备帧预算动态决定拖动期间的渲染策略，多节点画布优先保证拖动跟手，少节点画布保持完整实时内容。
+ [新增] 画布浮层边界计算与节点工具栏避让测试，工具栏在卡片上方优先显示，垂直方向按顶部栏、底部工具栏和视口边界避让。
+ [新增] 开发环境启动、重启、状态检查和备用工作台入口工具，降低本地服务异常退出后的恢复成本。
+ [新增] 图片节点状态区分：分别显示空槽、生成中、生成完成后的图片加载中和失败状态。
+ [优化] 多画布节点拖动与缩放：拖动期间合并位置更新、减少布局参与和可见范围计算，缩放结束后再恢复完整内容。
+ [优化] 图片节点和关系连线渲染，按视口裁剪并减少高频 React 提交，低倍率大画布操作更流畅。
+ [优化] 画布节点工具栏定位，保持水平位置稳定，仅在垂直方向避让遮挡区域，不再横向跳动。
+ [优化] 变体勾选状态直写关联参数元数据，避免每次点击提交整张画布操作，连续选择时减少无关更新。
+ [优化] Excel 画布入口与产品数据边界，关闭已下线 Excel 功能的用户入口，同时保留已有工作表、产品和回收站数据恢复能力。
+ [优化] 本地存储容量统计、恢复和回收站操作，兼容旧数据并改善错误提示与清理失败后的状态展示。
+ [修复] 画布顶部栏、版本入口、浮层层级和空白区域点击冲突，避免工具栏或提示层遮挡节点操作。
+ [修复] 产品参数卡、商品策划、图片审核、翻译配置和生成历史的状态回写，避免跨产品串用任务或来源。
+ [修复] 图片结果尺寸、比例和上游原图保存逻辑，规格不符时保留真实内容并显示实际尺寸，不拉伸或裁切。
+ [修复] 画布复制、粘贴、参考连线、节点定位和选择参考流程，保留关联关系并修正聚焦偏移。
+ [修复] 服务启动与开发版切换，编译失败时保留上一份成功版本，服务退出后可通过状态检查和备用入口恢复。

+ [优化] 编辑框输入体验：输入和长按删除期间使用本地草稿，停止编辑后一次性回写，避免逐字符重渲染。
+ [优化] 保存调度：输入或删除后持续1秒无变化才保存，连续操作只保留最后内容，显式检查点仍立即保存。
+ [优化] 上游图片容错：可解码但尺寸或比例不符合时仍保存上游原图，记录实际尺寸，不拉伸或裁切。
+ [修复] WAL写入阻塞：容量统计先释放只读事务再执行慢速分类，避免长读统计阻塞画布保存。
