# 生图工作台 Web 2.0.0-beta.17

修复「一键执行所有生成配置卡片」期间，画布累计素材超过任意总字节门槛后保存被拒绝、任务确认无法完成的问题。

- 移除整张画布累计媒体字节上限，图片批次逐张回写时不会因历史素材与本次生成素材合计过大而被存储层拒绝。
- 保留单媒体大小限制、SHA-256 分片校验、重复媒体去重、10,000 个媒体引用保护及 SQLite 磁盘余量检查。
- 增加超过 1 GiB、共 40 张图片的批量保存回归；逐张等待 SQLite 确认，验证 40 次根记录提交全部成功。

已有 Web 安装版：打开「设置 → 软件更新」，开启「开发者模式」以接收 Beta，检查、下载并安装。请等待画布已保存及生成任务结束，按当前版本提示操作。产品、工作簿、素材与个人配置保留。

首次安装：下载 `Web-v2.0.0-beta.17-macos-arm64.zip`，解压后双击「安装工作台.command」，然后使用桌面入口或「启动工作台.command」。默认3000端口，占用时自动顺延；Source code 不是安装包。

适用于 Apple Silicon Mac，沿用原可信签名。Stable v1.2.8保持原有发布状态。本次未执行收费生成。
