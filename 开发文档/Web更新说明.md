## 2.0.0-beta.27 - 2026-11-08

+ [新增] 产品参数增加“需要在图片中展现的关键词”，AI按图片用途选择展示，并安排字体、层级和构图位置；数量、尺寸等必要标注继续保留。
+ [新增] 系统提示词按生图、文本、视频、音频分类，生图策划角色可直接编辑、保存和恢复默认，各分类使用独立编辑内容。
+ [新增] 普通文本和商品双语提示词支持AI优化，提供快捷优化方向，确认应用后更新原卡片并保留连线与参数。
+ [新增] 商品中英文提示词支持短语对应高亮与联动滚动，方便核对数字、单位和参考信息。
+ [新增] 当前产品胶囊滑出可视区域时，在对应边缘显示方向和产品名，点击可平滑定位回来。
+ [优化] 点击产品胶囊立即切换，旧画布在后台保存；连续切换不等待保存或选中动画结束。
+ [优化] 热画布保留五分钟，安全空闲后才休眠；生成中、有未确认保存或未完成编辑的画布继续保留。
+ [优化] 保存防抖先合并快照再序列化，减少连续编辑时重复遍历整幅画布。
+ [优化] 生成历史、总览任务和已选详情按可视范围渲染，减少长列表挂载和屏外原图读取。
+ [优化] 历史素材检查复用文件索引，后台页面暂停无用轮询与循环动效，降低持续资源开销。
+ [优化] 顶部选中胶囊连续滑动，按距离调整速度与弹性；动画中再次点选会从当前位置改向。
+ [优化] 面板展开和关闭统一使用原生窗口与遮罩过渡，快速开关保持连续。
+ [优化] 下拉菜单、设置浮层和弹出面板支持点击外部关闭，嵌套选项保持原有操作。
+ [优化] 页签和分段控件的内容统一淡出淡入，下划线复用同一弹簧动效。
+ [优化] 按钮按压、开关滑块和列表选择模式使用统一反馈，尊重系统减少动态效果。
+ [优化] 节点定位与缩放可连续改向，滚轮、拖动和缩放控件可立即接管自动定位。
+ [优化] 生成历史与总览排序增加原生位置过渡，选择和下载清单保持完整。
+ [调整] 生成历史与总览先按图片名称末尾的数字编号排序，同一编号再按名称排列。
+ [调整] 恢复顶部产品胶囊悬浮时的灰色阴影。
+ [优化] AI策划、优化及翻译反馈实际请求、校验和保存阶段，缺少模型配置时提供设置入口。
+ [修复] 提示词失效时点击生成，强调已有常驻提示，不再叠加重复错误提示框。
+ [修复] 画布恢复完成后再次闪现加载骨架，以及启动时浅色主题短暂切成深色的问题。
+ [修复] 删除或恢复产品画布时错误进入空白状态、旧读取覆盖新状态及错误阻止恢复的问题。
+ [修复] 回收站恢复卡片后撤销时同步恢复回收记录，避免卡片从画布和回收站同时消失。
+ [修复] 退出列表选择模式时卡片抖动，以及关闭总览后悬浮说明残留或遮挡内容的问题。
+ [修复] 设置按钮再次点击无法关闭、页签下划线首次跳位，以及已保存开关在打开面板时重播切换的问题。
+ [修复] 编辑框左侧聚焦描边被滚动区域裁剪，保留原有紧凑间距。
+ [修复] Excel下拉面板异常变宽和产品胶囊删除按钮在鼠标移开后常驻的问题。
+ [修复] 定位到节点时不再把视区变化显示为长时间内容保存。
+ [修复] 同名Excel工作簿和产品切换时的导航归属与显示，减少画布难以找到的情况。
+ [修复] 去掉生成图片名称开头错误拼接的分隔符，保留编号和用户手动名称。
+ [修复] 界面异常提供诊断和重试入口，避免错误后仅显示白屏。
