# 生图工作台 Web 2.0.0-beta.19

修复 beta.17 因“任务 ID 已生成、但没有图片结果”而无法继续升级的问题。

- 图片任务没有收到可保存结果时自动记为失败，不要求用户逐条核实，也不自动重新发送上游请求。
- beta.17 旧账本不能直接写入“无结果失败”状态。新增签名包内的「修复升级入口.command」：仅在用户确认保存并关闭工作台页面后，核对 beta.17 安装、签名包和主管进程，再把已知无结果图片任务暂记为旧版可读的终态并重新启动 beta.17。升级到 beta.19 后，这些任务自动显示为失败。
- 仅处理图片账本中无结果的 `accepted`、`running`、`uncertain/upstream_result_unknown` 任务。结果保存未确认、视频任务和未知原因继续受保护。
- 原图片任务记录保留；不重发生成请求、不删除画布或媒体、不修改API配置、代理和个人设置。更新仍使用签名校验、独立进度页、版本事务和失败回滚。

## beta.17 客户的升级方式

如果 beta.17 的软件更新被无结果任务阻止：

1. 在 beta.17 的「设置 → 软件更新」开启「开发者模式」，检查并下载 beta.19。下载完成后点击一次「安装更新」，等待状态显示「安装包已暂存并再次验签」。此时按钮会变为「确认并安装」，先不要点击。
2. 保存并关闭所有生图工作台页面。在 Finder 按 `Command-Shift-G`，打开 `~/Library/Application Support/AI-Workbench-Web安装/版本/`，进入名称以 `2.0.0-beta.19-` 开头的目录。
3. 双击「修复升级入口.command」，在终端按提示输入「已保存并关闭」。等待 beta.17 自动恢复。
4. 打开原工作台，在「设置 → 软件更新」点击「确认并安装」；关闭工作台页面并保留更新进度页直到完成。

这样复用软件更新已下载并验签暂存的同一份包。准备命令会再次核验 GitHub beta.19 签名及包库存，只兼容处理没有结果的图片任务，不会重新发出生成请求。结果保存未确认、视频或其他未知任务仍会按原规则阻止更新。若目录里没有 beta.19 子目录，表示包尚未暂存完成，请回到软件更新页完成下载。

适用于 Apple Silicon Mac，沿用原可信签名。Stable v1.2.8未更改。本次使用隔离数据完成测试，未执行收费生成；Mac B实体安装仍需按上述步骤验收。
