## AI-Workbench v2.0.0-beta.29 - 2026-11-12

本次更新重点提升整套商品图的趣味设计，并完善AI策划的预览与恢复。图片编号、变体生成数量和任务状态更清楚，本地存储也增加了可预览的空间整理入口。

+ [优化] **趣味设计策划**：生图系统提示词加强标题造型、信息包装、手绘点缀和场景层次，并按不同商品品类选择表现方式。整套图片在统一风格下变化构图和设计组合，保留用户设定的每张图任务；图标、手绘和排版设计会进入实际中英文生图正文。
+ [新增] **策划实时预览**：在产品参数卡点击“AI写提示词”后，可查看正在生成的整套方案和真实阶段；完成后继续显示校验及保存状态，确认保存后才提示成功。
+ [新增] **图片编号与引用预览**：产品主图、资产、聊天和生图页的上传图片显示顺序编号；提示词、商品依据和优化面板中的图片引用显示编号、名称及缩略图，悬停可预览，点击可打开原图。
+ [优化] **变体生成数量**：生成设置明确区分“每个变体生成张数”和“实际总张数”，生成按钮同步显示合计；输入统计按各变体实际使用的提示词和参考图显示，悬停或键盘聚焦可查看明细。
+ [调整] **全局平台规则**：在参数卡的“平台规则 · 全局”入口编辑后，所有选择同一平台的产品和参数卡共用已保存的规则；不同平台分别保存。
+ [优化] **产品切换与任务通知**：顶部产品胶囊支持鼠标横向拖动，切换产品时将选中项滚至区域中心；AI策划的校验、修正和保存状态分别展示，完成通知按真实任务记录。
+ [新增] **本地存储整理**：在“设置 → 本地存储”中设置自动清理和保留天数，默认开启并保留90天；可扫描到期内容、预览存量整理范围，再确认清理。仍在使用的文件及待恢复任务受到保护，数据库空闲空间可另行确认“释放到磁盘”；生成响应与画布图片共用存储，减少重复占用。

+ [修复] **策划编号与待确认条件**：修复图片编号无效、重复或条件提示词不完整时无法继续的问题。可安全整理的编号自动修正；存在歧义或条件不完整时保留候选和原卡片，可点击“继续修正”处理已有方案。
+ [修复] **原任务恢复与保存确认**：根据实际进度显示“查询原任务”“继续保存”“继续修正”或“重新策划”；卡片已生成但确认未完成时，继续核验原任务和保存结果，避免因其他自动保存更新而误报失败或重复策划。
+ [修复] **通知与画布操作**：修复复制图片触发旧完成通知、胶囊已读状态回退、单张结果定位、参数卡回收保存层级和小地图缩放保持问题；鼠标点击画布后正确接回键盘焦点。

+ [文档] **安装与更新**：本版为Apple Silicon macOS预览版。已有安装版可开启开发者模式，在“设置 → 软件更新”中检查更新。
+ [文档] **已有提示词与图片**：更新不会自动改写已保存的提示词或重新生成图片。新版系统提示词在之后的策划中生效；确认提示词后再手动生成。
+ [文档] **继续修正与重新策划**：“继续修正”会调用文字模型修正已有候选，可能产生文字模型费用；“查询原任务”和“继续保存”不重新提交整套策划。需要重新制作整套方案时再选择“重新策划”。
