## 2.0.0-beta.24 - 2026-11-04

+ [修复] 批量生图遇到本机查询超时或连接中断时，自动继续查询原任务，不再因一次超时停止取回图片。
+ [修复] 取图、保存确认途中断线后自动恢复，沿用原任务，不重复提交生成请求或重复添加图片。
+ [优化] 画布保存只读取图片引用所需信息，减少批量结果保存时的内存占用。
+ [新增] 产品参数卡支持填写商品资料，未识别 Excel 变量时也可直接准备生图。
+ [新增] “AI写提示词”根据商品资料策划整套图片与张数，提供英文提示词及中文对照。
+ [新增] 修改中文提示词后自动同步英文，翻译未完成或资料已变化时阻止使用旧提示词生成。
+ [新增] 产品变体支持分别上传参考图、共用商品资料，一次生成所有已选择变体的图片。
+ [优化] 产品主图支持多张上传、拖入本地图片及直接拖入资产图片，不限制上传张数。
+ [新增] 产品主图悬浮操作支持移除背景、还原原图及再次使用已保存的去背景结果。
+ [调整] Wildberries 默认选择俄语并允许更改；平台和语言选项扩充，统一下拉菜单交互。
+ [调整] 平台制作规则随任务传入 AI 策划，其他平台不再套用 Wildberries 规则。
+ [优化] 参数填写说明在悬浮时显示，拖放高亮与菜单开合反馈更加完整。
