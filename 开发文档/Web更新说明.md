# 生图工作台 Web 2.0.0-beta.10

本次更新集中改善保存、工作簿切换、连线交互及图片详情，并修复配置补齐误显示生成成功的问题。

- 修复只补齐生成配置及连线时，顶部产品胶囊错误变绿；真实任务的运行、成功和失败状态继续显示。
- 改善 Excel 工作簿与产品切换、SQLite 读取和保存；设置页签切换不再因未修改数据而反复触发保存，页面连接支持恢复与自动重连。
- 迁入圆角正交避障与共享主干连线，改善关系选择、同高吸附、路线稳定、数据流及端点交互；“整理卡片”支持符合条件的单线卡片并排。
- 恢复图片详情中的生成信息及下载入口，修复下载按钮点击穿透与浮层遮挡。
- 已保存的 API Key 在编辑框显示首尾脱敏信息，复制仍是脱敏文本；保留原凭据引用。
- 恢复在线更新进度展示，改善侧栏收窄显示、主题和浮层交互。
- 保留磁盘占用保护：自动备份关闭，日志轮换、更新包回收和构建临时依赖清理继续生效。

已有 Web 安装版：在“设置 → 软件更新”检查、下载并按提示安装；安装前等待保存完成、生成任务结束，并关闭工作台页面。数据、工作簿、媒体与个人配置保留。

首次安装：下载 `Web-v2.0.0-beta.10-macos-arm64.zip`，解压后双击“安装工作台.command”，再使用“启动工作台.command”。默认使用 3000 端口，被占用时自动顺延。请勿下载 Source code 作为安装包。

本版适用于 Apple Silicon Mac，沿用原可信签名与 Web 预览更新渠道。旧 Stable v1.2.8 保留。本机专项与服务检查不代表另一台实体 Mac 已验收；未执行收费生成。
