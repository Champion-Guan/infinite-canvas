# 生图工作台 Web 2.0.0-beta.16

修复「一键执行所有生成配置卡片」后，画布素材总量超过旧 512 MiB 门槛时保存被拒绝、任务确认无法完成的问题。

- 画布媒体总量按唯一内容分片计算；相同图片的重复引用不再重复占用容量。
- 单次画布读取/写入上限提高到 1 GiB，原有单媒体分片、磁盘余量与引用数量保护保持不变。
- 加入 540 MiB 批量生成端到端存储回归，逐片确认媒体落盘并验证画布根记录提交。

已有 Web 安装版：打开「设置 → 软件更新」，开启「开发者模式」以接收 Beta，检查、下载并安装。请等待画布已保存及生成任务结束，按当前版本提示操作。产品、工作簿、素材与个人配置保留。

首次安装：下载 `Web-v2.0.0-beta.16-macos-arm64.zip`，解压后双击「安装工作台.command」，然后使用桌面入口或「启动工作台.command」。默认3000端口，占用时自动顺延；Source code 不是安装包。

适用于 Apple Silicon Mac，沿用原可信签名。Stable v1.2.8保持原有发布状态。本次未执行收费生成。
