# 生图工作台 Web 2.0.0-beta.12

本次修复安装升级的管理进程交接、启动诊断及钥匙串助手接续，并随包提供 Smart 代理核心和最大 LightGBM 模型。

- 修复新版本仍由旧 supervisor 管理的问题。启动失败显示具体的脱敏原因，保留失败回退能力。
- 同源码沿用原已签名钥匙串助手；画布、保存和更新不再因凭据暂时未解锁而无法启动，真实凭据仍使用原密钥加密保管。
- 新版确认安装后排空保存、进入独立进度页，跨管理进程继续显示状态，成功后自动返回工作台。beta.9 等旧页面仍需关闭一次才能安装。
- 内置 Mihomo Smart 与最大的 Model-large.bin，启用 Smart 智能分组，同时保留手动选路。
- 核心及最大模型默认每天自动检查更新，下载校验后等代理空闲再应用，失败恢复原资源；可在网络代理设置中关闭或手动检查。
- 保留日志轮换、更新包回收和构建缓存清理；资源缓存有容量限制，不自动备份或删除客户数据。

已有 Web 安装版：设置 → 软件更新，检查并下载；等待保存完成和生成任务结束，再安装。早期版本按提示关闭工作台页面即可，其他网站可以继续使用。产品、工作簿、媒体与个人配置保留。

首次安装：下载 `Web-v2.0.0-beta.12-macos-arm64.zip`，解压后双击“安装工作台.command”，再使用“启动工作台.command”。默认使用3000端口，被占用时自动顺延。请勿下载 Source code 作为安装包。

适用于 Apple Silicon Mac，沿用原可信签名及 Web 预览更新渠道。旧 Stable v1.2.8 保留；本机验收不代表另一台实体 Mac 已验收，未执行收费生成。
