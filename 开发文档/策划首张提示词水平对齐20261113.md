# 策划首张提示词水平对齐

用户要求新出现的提示词卡与产品参数卡直线相连，避免高度只有少量偏差时产生小转弯。

原因：`商品提示词画布.ts`原先从参数卡顶边开始摆放540px高的提示词卡。当参数卡高度为520px等其他值时，两端中心高度不同。

修改：新建首张提示词使用`parameter.y + (parameter.height - 540) / 2`作为顶边，使中心端口同高。首行预留876px提示词与配置的整体空间，遇到已有卡片优先向右避让，保留垂直中心；配置仍与提示词中心同高。后续用途沿原行距向下排列。复用旧卡时不修改原位置和尺寸，不回排已有用户布局；连线路由和避障规则不变。

验证：34项商品策划及连线稳定测试通过，完整TypeScript检查通过。新增用例覆盖参数高度320/520/540/800、首行遇障碍向右排、重新策划保留旧卡手动位置，并调用实际路由确认无遮挡时只有两个同高端点。开发构建已成功。未调用收费策划，因此本次没有在实页重新生成方案验证；已有卡片不会自动挪动。
