# 设置页签横线对齐验收（2026-10-27）

## 原因与修改

现有 Chrome 的 localhost:3001 设置面板可重现“软件更新”横线向左偏约 9.924 屏幕像素。Tabs 在面板入场 scale(0.985) 期间缓存了缩放后的页签尺寸和位置；transform 动画结束不触发 ResizeObserver。全局页签悬浮 translateX(1px) 还会让文字与独立横线产生额外错位。

- `扩展功能/存储界面/设置页签测量.tsx`：监听设置内容及祖先真正的 animationend/animationcancel，重新挂载导航条以更新 Tabs 的测量缓存。Modal 动画可能在子组件 effect 后启动，因此不使用挂载时 getAnimations() 的快照。仅导航条重测，设置内容和表单不重新挂载；保存并恢复导航条键盘焦点，卸载时移除监听。
- `上游适配/设置页签入场测量修复.patch`：接入独立模块，通过 Tabs 的 item 语义样式禁止本面板页签横移。保留原面板缩放、淡入和横线过渡，不用固定偏移或假 resize 修正，不修改全局动效。
- `上游适配/开发源码映射.json`：登记模块、单功能补丁及指纹。

没有修改旧3000服务、业务数据、凭据、代理、生成或升级逻辑，没有新增测试窗口和工程副本。
