# 全部页签双向过渡与设置开关验收

后续修订：本记录中的设置窗口 `ant-fade` 特例已按用户要求取消，恢复 `AppleModal` 默认原生窗口动效；横条改为统一的布局坐标测量与原生弹簧，不再用改变窗口动画规避测量。后续设计以 `基础交互动效规范.md` 为准。

## 范围与实现

- 左侧画布、资产、提示词库、生成历史、回收站使用共用 `TabContentTransition`。
- 设置、模型选择及插件管理接入 `NativeFadeTabs`，保留 Ant Design 原生导航、内容缓存和双向 CSS 淡变。
- 模型列表、Agent 各内容页、日志文本/JSON及过滤分组、节点信息/JSON、生成配置模式和浮动提示词模式使用相同内容交接。
- 顶部产品页签对已有画布实例执行透明度交接，不通过动画重新挂载画布；五分钟安全空闲释放、生成任务驻留和保存门禁保持原机制。
- 自定义交接由 Web Animations API 播放 180ms 透明度动画，无逐帧 JavaScript 调度和固定卸载定时器。中断时先读取当前透明度再取消旧播放器；过期完成回调不能移除新内容。
- 自定义内容至多保留当前页和最近一层退场页；退场层立即 inert、aria-hidden 且不可点击，动画完成后卸载。减少动态效果或动画 API 不可用时直接呈现最终状态；隐藏产品及页面隐藏会清理退场层。
- 生成历史原有独立入场和逐项延迟已移除，避免与共用交接叠加。

## 设置面板的两处修复

1. 顶栏设置按钮原本已有开关逻辑，但外部点击捕获先取消弹窗，按钮随后的 click 又将其打开。现在按钮通过明确的触发器 ID 登记到弹窗边界，同次点击不再先关闭再重开，其他外部点击仍正常取消。
2. 原设置内容和弹窗同时缩放，动画完成后又通过重新挂载导航来校正测量，引起横条宽度和位置闪变。设置窗口改用 Ant 原生 `ant-fade`；移除内容缩放及导航重挂载。首次打开的测量阶段不插值横条宽度，原生窗口打开完成后恢复正常页签横条过渡。

## 实页验证

沿用现有 Chrome 和 `http://localhost:3000`，没有建立独立测试工作台：

- 五个侧栏页签连续切换，新旧内容同时存在并交接。例如新资产透明度 0.97586、退场画布 0.02414；其他页签的退场层也采样到中间值并保持 inert。无横向溢出，完成后清理旧层。
- 设置原生过渡采样到旧页透明度 0.965→0.069、新页 0.035→0.931；方向键移动焦点及 Enter 激活均保留原生行为。
- 模型新获取/已有列表双向交接，原有 4 个勾选保持。仅查看后取消模型窗口和渠道编辑，没有拉取模型或提交渠道改动。
- 节点信息/JSON 双向交接，快捷键隔离属性保持，无横向溢出。
- 生图模式切到文本时采样到新内容 0.375、旧内容 0.625，随后恢复原生图模式。没有启动生成任务。
- 顶部热产品交接采样到新画布 0.9898、旧画布 0.0102。旧产品立即 inert，淡出后隐藏，缓存实例仍保留。
- 设置按钮连续重复点击，aria-expanded 依次为 false、true、false、true，关闭不会立刻重开。
- 重新打开末尾“软件更新”页签，连续 6 次采样横条中心与选中页签中心偏差均为 0，宽度稳定为 56.0069px；内容与窗口 transform 均为 none。此前曾出现约 8.85px 偏差、横条宽度缩至约 10.98px 后恢复。
- Agent 与插件入口受既有产品开关关闭，本轮仅做代码接线、类型及回归验证，没有开启这些功能；减少动态效果通过自动化用例验证，未改变用户系统偏好。
