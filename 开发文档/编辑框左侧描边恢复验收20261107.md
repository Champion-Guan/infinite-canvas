# 编辑框左侧描边恢复

## 原因与修复

- 实页复现：商品英文提示词编辑框、设置的系统提示词编辑框紧贴滚动区域左侧。四边 border 均存在，但向外绘制的聚焦阴影被滚动容器裁剪，造成左侧描边缺失。
- 统一将公共表单聚焦描边改为内侧绘制；Tailwind ring 使用 inset，Ant Design Input 和 InputNumber 通过正式主题 token 配置内侧 active/error/warning shadow，继续使用当前主题的颜色及宽度。
- 沿用现有原生 CSS 过渡，不新增事件监听、逐帧调度或依赖。不增加滚动条留白，不改变字段尺寸、双语标记层和表单数据逻辑。
- 作者文件由补丁维护器导出两个独立接入补丁，并登记前后状态与指纹。

## 验证

- 来源检查：651 文件、2093 引用、458 接入补丁，一致。
- 用户体验代码检查、有界 TypeScript 检查通过。双语联动、启动主题与统一动效现有 11 项测试全部通过。
- 当前 http://localhost:3000 重新加载后，浅色和深色的画布英文提示词与设置系统提示词均为内侧聚焦描边，左侧完整可见。
- 画布编辑框聚焦后宽 270.640625px；设置编辑框聚焦和 Tab 失焦后均宽 920.017395px，与修复前一致。相应滚动容器左侧额外 padding 仍为 0px，均无横向溢出。
- 设置系统提示词仍为空，验收只点击聚焦和切换主题，没有输入内容或调用模型。结束时恢复浅色、关闭设置，当前画布显示已保存。
