# 产品胶囊切换居中验收

日期：2026-11-12。当前开发页：`http://localhost:3000`。

切换产品后，选中胶囊从原来的“只保证可见”改为平滑滚到胶囊区域中心。首尾受实际滚动范围限制，不增加空白占位。沿用浏览器原生滚动，连续切换以最新目标为准；减少动态效果时直接定位。

边缘“当前产品”定位入口使用相同居中规则。手动横向浏览不强行居中，胶囊状态变化也不触发重新滚动。原有产品选择、状态清空和画布保存流程不变。

验证结果：

- 胶囊滑动与鼠标拖动相关测试共 23 项通过，覆盖已完全可见的胶囊、连续改向、首尾限制、手动浏览、显式定位、键盘和减少动态效果。
- 完整 TypeScript、源码装配及差异空白检查通过。装配 695 个文件一致、2288 个引用有效，旧前端引用为 0。
- 原 Chrome 页面刷新后，点击“未命名产品5”和“未命名产品4”，稳定位置与胶囊区域中心偏差均为 0 像素；左右连续切换后落在最新产品。
- 手动向左浏览后保持滚动位置 0，选中项仍为“未命名产品4”；点击右侧定位入口后重新居中，偏差为 0。
- Home 定位首项，scrollLeft 为 0；End 定位末项，scrollLeft 为 932.5，接近导航最大值 933，无越界。
- 验收结束恢复原“未命名产品8”，142 个节点，显示已保存，浏览器错误日志为空。未上传或删除素材，未调用收费生成。
