# 产品画布有界缓存验收

日期：2026-11-06，Asia/Shanghai。

## 问题与结果

`ProductWorkspace` 原先将访问过的产品一直放入 `visited`，只在产品被移除时卸载。虽然隐藏产品已不渲染节点，画布组件、Hook、订阅、撤销栈和业务闭包仍随访问数量累积。

本轮改为最近使用缓存：空闲实例预算为 2，包含当前产品和最近一个产品。超过预算后，后台检查最久未使用的产品，完成真实画布保存与会话休眠后卸载。切换不等待淘汰过程。运行中的任务、未确认保存和未完成编辑窗口获得临时保护，可暂时超过预算；不会为凑足数量而强制取消任务或丢弃编辑。

两个实例是针对当前设备采用的保守初始预算，不是通过性能基准得出的最优值。

## 实现与保护

- `扩展功能/产品/画布缓存规则.ts`：最近访问顺序、后台单轮淘汰、导航代次和迟到回调校验，不进行持续轮询。
- `扩展功能/产品/画布驻留保护.ts`：按产品记录工作租约，异步入口在第一个 await 前取得保护，完成或失败后释放；实例身份与最新检查点共同决定是否允许卸载。
- `扩展功能/产品/产品工作区.tsx`：替换永久累积逻辑，淘汰提交读取已提交的 React 状态，同步完成最终卸载，避免重试更新留下旧实例。
- `扩展功能/产品/产品保存检查点.ts`、`产品操作.ts`、`画布保存接线.ts`：只有当前快照确认持久化、检查点空闲且任务门禁放行时，才准备休眠。保存期间新增编辑、重新访问或实例换代会使旧释放证明失效。
- `扩展功能/产品/画布休眠状态.ts`：撤销、重做、选择和操作工具写入现有 SQLite `prompt_cache` 的产品独立键，按产品覆盖。序列化为 Blob，存储层保留二进制描述，不将完整历史对象树移到全局 Map 中继续常驻；图编码保留共享引用和 undefined。
- 原业务内容和视区仍由原画布保存体系维护。休眠记录只用于同一页面会话，跨刷新保持原来的撤销栈重置语义，避免复活旧 Blob URL；外部编辑导致版本改变时不应用旧撤销栈。
- 画布内生成、结果保存、重试、上传、裁剪、拆图、放大和截帧等异步回调接入工作保护；策划、商品翻译、提示词优化、资产插入和任务确认也有相应保护。
- 未完成的标题或图像编辑窗口、插件管理和素材选择窗口保持原实例。未知且无法序列化的插件状态保守保留，不删字段强行休眠。
- 冷画布显示恢复状态；读取失败显示错误和“重试恢复”，不加载空画布冒充成功。休眠读取完成后再次读取最新产品，拒绝已删除或过期目标。

保持根目录为唯一来源，作者画布入口变更由 3 份单一功能补丁维护。未手工维护装配后的运行输入，未修改上游仓库。

## 实页证据

使用现有 localhost:3000、原工作区和既有产品，未触发收费生成、未删除产品或媒体。

1. 依次访问多个产品，导航先完成，保存/休眠期间临时出现 3 个或更多实例，随后收敛到 2 个。通过 `[data-product-active]` 确认旧产品容器实际消失，而不只是隐藏节点。
2. 在“粉色皇冠数字蜡烛”的原空白“风格或竞品参考”字段添加临时验收文字，确认保存与撤销可用，切至其他产品使原画布实际卸载。
3. 返回原产品后，临时文字、69% 视区和撤销记录恢复；撤销清空字段、重做恢复文字、再次撤销还原原空值，最终保存确认。
4. 最终修订重新加载后，再次轮换“未命名产品4”“未命名产品3”并返回原产品。缓存最终为 2 个实例，两者均“已保存”，alert 和 console error 均为空，34 个原画布元素仍保留。
5. 最终冷恢复前后视区均为 `translate(107.496px, -657.388px) scale(0.684179)`。此前临时编辑验收视区为 69%；最终用户页面显示 68%，未用旧验收值覆盖当前页面。

## 边界

- 本轮解决挂载实例随访问量增长的问题。Zustand 中所有产品的业务总数据、存储编码缓存和原媒体地址缓存不属于该实例预算；不宣称总浏览器内存已经限制到固定 MB。
- 本轮未测长期运行 RSS、JavaScript 堆回收或大型画布 FPS，不以浏览器标签页内存提示和工具调用耗时代替基准。
- 工作与失败保护允许临时超额。任务状态由现有业务决定，未为限制实例数改写远端任务状态。
- 真实任务/保存故障用可控测试验证，实页未提交收费生成、未制造数据库断网或强杀故障。
- 冷产品需要读取会话状态并重新挂载，热缓存保留两产品之间的快速切换；不承诺所有访问过的产品永久秒切。
